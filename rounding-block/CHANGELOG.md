# 변경 기록

## 1.5.0

- 곡면 템플릿을 소유 옥탄트별 최종 좌표로 미리 색인해 청크 메시 생성 중 영역 탐색·소유권 판정·전체 블록 재할당 제거
- 곡률과 법선 흐름이 정확히 선형인 연속 쿼드만 병합해 외형을 유지하면서 보관 프리미티브·버텍스 수와 메시 출력량 감소
- 전체 블록 이웃 스캔과 가중 모델 쿼드 선택의 작업 버퍼를 스레드별 재사용해 청크 작업자의 단명 객체와 GC 압력 감소
- 대각선 접촉 쌍을 마스크마다 한 번만 분석하고 샘플 계산 버퍼를 재사용해 곡면 템플릿 준비 시간과 임시 할당 감소
- 옥탄트 분할이 끝난 원본 템플릿과 테스트 전용 접근 경로를 제거하고, 월드 메시 생성 중 빈 템플릿 이동 벡터·오목면 임시 객체 생략
- 면으로 닿지 않고 모서리나 꼭짓점만 공유하는 블록도 기본 곡면 메시가 접촉점까지 이어져 가운데 배경이 비치지 않도록 처리
- 대각선 점유가 섞인 표면 셀을 여러 곡면 조각으로 분리해 모서리 돌기·겹침·비정상 정점 결합 제거
- Fabric 공식 유체 렌더 API로 기존 바닐라·Sodium 물 렌더러를 감싸고 실제 라운딩된 이웃 블록의 접촉 빈 공간에만 수면 패치 추가
- 넓은 바다와 라운딩 블록이 없는 물은 기존 유체 메시를 그대로 사용해 추가 정점과 접촉 메시 계산을 생략
- 바닐라와 같은 네 모서리 수면 높이 가중치로 흐르는 물의 경사와 라운딩 블록 접점을 연결
- 물 색상·광량·정지/흐름 UV·양면 수면을 기존 유체 핸들러에서 이어받아 리소스팩과 Sodium/Iris 경로 보존
- 접촉 패치를 방향별 고유 영역으로 잘라 물이 블록 여러 면을 둘러싸도 투명면이 중복되지 않도록 처리
- `fluidContactPlans` 캐시와 `/roundingblock cache fluidContactPlans` 명령 추가
- `enabled=false`에서는 원래 물 핸들러와 Sodium의 비재정의 상태까지 복원해 유체 라운딩 경로를 타지 않도록 처리

## 1.4.0

- JSON 최상위 `enabled`로 모드를 켜고 끌 수 있으며, 비활성 모델 베이크에서는 수정 콜백·블록 상태 색인·곡면 템플릿·메시 캐시를 모두 생략
- 비활성 재적용이 끝나면 모든 블록 모델이 바닐라 모델로 교체되어 월드 렌더에서 라운딩 래퍼를 호출하지 않음
- `/roundingblock` 클라이언트 명령으로 활성 상태, 품질, 캐시, 진단 로그 값을 JSON에 저장하고 즉시 모델 재적용
- `/roundingblock reload`로 직접 편집한 JSON을 게임 재시작 없이 다시 읽어 곡면 템플릿과 캐시까지 교체
- 리로드 세대마다 지원 블록 형상표를 분리해 이전 화면 렌더와 새 모델 베이크의 상태가 섞이지 않도록 수정
- 설정 명령의 리소스 재로드가 실패하면 활성 설정과 명령으로 저장한 JSON을 직전 값으로 복구

## 1.3.0

- `config/rounding-block.json`에서 곡면 반경과 분할 수를 변경할 수 있도록 사용자 설정 추가
- 전체 블록·반블록·복합 형상 메시 캐시와 가중 모델 변형 캐시의 최대 항목 수를 각각 설정 가능
- 잘못된 항목만 안전한 기본값으로 복구하고, JSON 문법이 깨진 파일은 덮어쓰지 않은 채 기본값으로 실행
- 기본 품질 설정은 기존 템플릿을 공유하고 사용자 품질 설정일 때만 해당 템플릿을 시작 시 한 번 생성
- 진단 로그 출력 여부를 설정으로 제어하며 설정값은 클라이언트 렌더 초기화 전에 확정

## 1.2.0

- 곡면 분할 수를 유지하면서 같은 평면의 인접 쿼드를 병합해 청크 버텍스와 VRAM 사용량을 줄였습니다.
- 캐시가 찬 뒤에도 최근 지형 패턴을 재사용하고, 동시 청크 작업의 같은 메시 중복 생성을 막았습니다.
- 버텍스마다 만들던 임시 UV 객체를 제거해 청크 빌드 할당량을 줄였습니다.
- 가중치 모델의 블록별 선택은 유지하면서 이미 본 쿼드 조합의 면·UV 분석 결과를 재사용합니다.
- 유한한 256개 곡면 템플릿을 모델 준비 중에 미리 생성해 플레이 중 처음 보는 지형에서 생기던 메시 준비 지연을 없앴습니다.
- 이웃 좌표, 방향 배열, 미세 점유 비트에 생기던 짧은 수명의 임시 객체를 제거해 청크 재구성 시 GC 압력을 낮췄습니다.
- 리소스팩을 다시 불러올 때 이전 베이크에서만 지원되던 블록 형상을 비워 잘못된 이웃 연결이 남지 않게 했습니다.
- 계단 한 방향에 여러 텍스처 조각이 있을 때 각 조각의 UV 영역을 보존하고, 곡면 위치에 맞는 조각과 오버레이만 선택합니다.
- 계단의 실제 렌더 윤곽을 `2×2×2` 반칸 점유 상태로 변환해 방향·상하·직선·안쪽·바깥쪽 형태 라운딩
- 계단과 전체 블록·반블록이 맞닿는 구역은 하나의 반칸 격자로 메시를 만들어 내부면과 접점 틈 방지
- 계단 모델의 부분 쿼드에서 면 방향과 UV 변환을 읽어 곡면에도 원래 텍스처 방향 유지
- 계단이 없는 구역은 기존 전체 블록·세로 반블록 전용 경로와 캐시를 그대로 사용
- 계단 점유 수, 이웃 블록 좌표, 메시 범위, 전체 블록 접점 회귀 검사 추가
- 원목처럼 불투명한 블록이 투명 구멍이 있는 나뭇잎을 완전한 가림 이웃으로 취급해 면을 지우던 문제 수정
- 원목→나뭇잎은 면을 유지하고 나뭇잎→원목·나뭇잎→나뭇잎 및 부분 블록 접합은 유지하는 비대칭 가림 검사 추가
- 일반 전체 블록 지형에서는 반블록·계단용 세부 점유 격자를 만들지 않고, 필요한 이웃에서만 두 번째 세부 검사를 수행하도록 청크 재구성 비용 절감
- 이웃 노출면 판정을 기존 3×3×3 순회에 합치고, 층 판정·미세 셀 점유를 비트 연산으로 바꿔 반복 분기와 임시 할당 감소
- 정적 모델은 베이크 이후 필요 없는 쿼드 분석 캐시를 보관하지 않고, 최초 진단 로그도 성공 뒤 핫패스 자료구조 조회를 생략

## 1.1.0

- 상단·하단 반블록의 실제 높이를 읽어 해당 1/2칸 안에서만 엣지와 꼭짓점 라운딩
- 반블록과 전체 블록을 세로 1/2칸 점유 상태로 함께 해석해 맞닿는 면, 단차, 안쪽 코너를 하나의 연속 표면으로 연결
- 반블록의 가운데 윗면·아랫면처럼 컬 방향이 없는 쿼드도 실제 좌표로 여섯 면에 분류해 원래 UV 유지
- 이중 반블록은 내부 중앙면을 만들지 않고 전체 블록 경로로 처리
- 반블록이 없는 이웃은 기존 27비트 메시와 캐시를 그대로 사용해 일반 지형 비용 유지
- 상·하단 높이, 평평한 반블록 지형 우회, 반블록-전체 블록 접점의 열린 선분·중복 면 회귀 검사 추가

## 1.0.0

- 곡면 템플릿을 8개 옥탄트로 분할하고 고체 영역의 평면·볼록 조각과 빈 코너의 오목 조각을 생성 단계에서 구분
- 오목 조각은 고유한 인접 고체 블록이 끝까지 소유하도록 해 바닥·벽 사이 연결 면과 코너 패치 누락 방지
- 원본 평면 대체 과정에서 오목 조각은 제거하지 않고, 오목 곡면이 닿는 면은 완전한 커스텀 표면으로 유지
- 일반 평면·볼록 조각은 자기 블록 0~1 안에서만 출력하고 오목 연결 조각에만 제한적으로 블록 밖 좌표 허용
- 원본 평면을 실제 렌더 순서대로 합성한 다중 블록 단차 장면의 열린 선분·중복 삼각형 회귀 검사 추가
- 충돌 상자 대신 베이크된 6면 렌더 모델을 지원 기준으로 사용해 진흙과 일반 JSON 기반 모드 전체 큐브 지원
- 옥탄트 분할 결과를 256개 꼭짓점 형태별로 캐시하고 계획 필터의 임시 할당을 줄여 동일 출력 기준 메시 생성 비용 절감

## 0.3.6

- 곡면 고체를 원래 복셀 합집합 안으로 제한해 빈 공간으로 튀어나오거나 이웃 블록 영역을 침범하던 구조 제거
- 모든 곡면을 각 블록의 0~1 경계에서 분할하고 경계 위 조각은 한 블록만 소유하도록 통일
- 같은 높이의 3×3 평면이 이어지면 옆에 한 칸 높은 블록이 있어도 중앙 면은 원본 평면으로 유지
- 원본 평면으로 대체되는 방향은 `FACE` 분류뿐 아니라 해당 면 쪽 절반의 모든 커스텀 조각을 제거
- 평지 옆 단차, 블록 내부 좌표, 256가지 접점 중복·열림을 함께 검사하는 회귀 테스트 추가

## 0.3.5

- 3×3×3 이웃이 완전한 평지·평벽인 블록은 외형 분석과 라운드 메시 생성을 모두 건너뛰고 원본 모델을 바로 출력
- 곡면 분할을 4에서 3으로 조정해 모양을 유지하면서 경계 블록의 출력 프리미티브 수 절감
- 메시 계획 캐시를 64개에서 256개로 늘려 다양한 지형에서 캐시가 찬 뒤 같은 형상을 계속 재생성하던 비용 완화
- 캡처에서 평면 균열로 보인 색상 윤곽선은 조준 중인 블록의 선택 테두리임을 원본 해상도로 확인

## 0.3.4

- 평지 블록 전체를 바닐라 모델로 우회하던 경로를 폐기하고 평평한 방향의 원본 쿼드만 선택적으로 합성
- 바닐라 평면을 쓰는 블록도 이웃 코너를 대신 소유한 모든 곡면 조각을 계속 출력하도록 수정
- 평면 대체 시 `FACE` 조각만 제거하고 `EDGE` 곡면 개수는 절대 줄지 않는 회귀 테스트 추가
- 원본 쿼드 방향 필터는 Fabric 렌더 변환 스택으로 적용하고 호출 직후 항상 해제

## 0.3.3

- 평지 우회 조건을 블록 전체 층 모양이 아니라 실제로 보이는 각 면의 3×3 평면 조건으로 변경
- 평면 뒤쪽의 무관한 지형 때문에 커스텀 메시로 되돌아가던 문제 수정
- 완전히 평평한 공유 정점은 곡면 쪽 정점까지 함께 블록 경계에 맞춰 바닐라 면과 커스텀 면 사이의 미세한 높이 차 제거
- 평면 뒤쪽 점유가 달라도 바닐라 면을 유지하는 회귀 테스트 추가

## 0.3.2

- 평지와 평벽은 커스텀 메시를 만들지 않고 바닐라 면을 그대로 사용해 쉐이더에서 블록마다 쿠션처럼 보이던 조명 굴곡 제거
- 실제 바깥·안쪽 엣지의 곡면을 2분할에서 4분할로 높여 실루엣을 부드럽게 개선
- 평면 구간은 곡면 비용을 전혀 쓰지 않고, 경계 블록에만 세분화 메시를 적용하는 혼합 렌더 경로 추가
- 256가지 접점 정합성에 더해 평면 높이·노멀과 평지 우회 조건 회귀 테스트 추가

## 0.3.1

- 평면까지 잘게 쪼개던 사면체 메시를 교차 간선당 쿼드 하나를 만드는 표면망 방식으로 교체
- 템플릿 경계를 바깥에서 생성한 뒤 블록 중간면에 맞춰 잘라 이웃 블록 사이의 열린 틈 방지
- 연속 법선 보간은 유지하고 곡면 실루엣을 2분할로 제한해 고립 블록은 256개, 평평한 지형은 64개 이하의 프리미티브만 출력
- 실제 프로필에서 확인된 NVIDIA `GL_OUT_OF_MEMORY` 회귀를 막는 메시 예산 테스트 추가

## 0.3.0

- 블록별 엣지·끝마개·코너 패치를 폐기하고 월드 꼭짓점 주변 8블록을 한 번에 해석하는 메시 생성기로 교체
- 평면 경계는 유지하면서 격자 엣지와 꼭짓점 반경 안에서만 곡률이 생기는 연속 밀도 표면 적용
- 빈 블록 쪽으로 이어지는 오목 곡면도 단일 고체 소유자가 출력해 위·아래 접점의 돌출 캡과 열린 틈 제거
- 256개 꼭짓점 점유 조합을 실제 다중 블록 월드 좌표로 조립해 중복 삼각형과 열린 경계를 검사
- 곡면 분할을 5와 연속 법선 보간으로 구성하고 점유·메시 계획을 캐시해 프레임마다 형상을 다시 계산하지 않도록 유지

## 0.1.7

- 노출면 하나만 가진 대각 블록이 `3고체+1빈칸` 접점에 닿을 때 해당 귀퉁이만 국소 전이 패치로 라운딩
- 평평하게 이어진 블록 경계와 일반 노출면은 기존 평면을 유지
- 완전히 가려진 블록은 UV와 이웃 토폴로지를 계산하기 전에 종료해 청크 재빌드 비용 절감
- 가중치 모델의 동일 쿼드 UV 해석 결과를 재사용하고 임시 블록별 진단 순회 제거

## 0.1.6

- 오목 필렛이 대체하는 기존 평면을 반지름만큼 잘라 곡면과 평면이 겹치던 세로 띠 제거
- 오목 필렛의 노출된 양 끝을 재질이 유지되는 부채꼴 캡으로 닫아 검은 단면 균열 보정
- 완전 차폐 블록의 `cutoutMipped` 렌더층을 허용해 잔디 블록의 기본층과 색상 오버레이 라운딩 활성화

## 0.1.5

- 세 고체 블록과 한 빈칸이 만나는 2x2 단면을 판정해 바닥·벽의 오목 엣지 라운딩 추가
- 오목 곡면을 두 재질이 절반씩 그려 모래·흙처럼 서로 다른 블록 접점에서도 원래 텍스처 유지
- 잔디 블록 옆면의 기본 텍스처와 색상 오버레이처럼 면당 여러 쿼드를 사용하는 전체 큐브 지원

## 0.1.4

- 바닥처럼 다음 라운드 엣지가 이어지지 않는 접촉면에만 끝마개를 추가해 밑면·바닥 접점 보정
- 이어지는 블록 엣지에는 내부 끝마개를 만들지 않도록 이웃 블록 형상 판정 추가
- 곡면 분할을 3에서 6으로 늘려 엣지와 꼭짓점을 더 부드럽게 표시
