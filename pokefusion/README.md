# PokemonFusion

`/pokefusion`으로 여는 서버 주도형 포켓몬 합성 GUI입니다. PokemonToItem으로 만든 포켓몬 아이템을 베이스 1마리와 재료 최대 9마리까지 넣을 수 있습니다.

- Shift+클릭하면 베이스부터 먼저 들어가고 이후 재료가 순서대로 채워집니다.
- 재료 칸은 필요한 만큼 한 칸씩 늘어나며 매번 중앙에 맞춰 재배치됩니다.
- 최종 IV에 기여하는 재료에는 GUI 안에서만 인챈트 광택이 표시됩니다.
- 합성하면 베이스가 같은 진화 계보의 재료들이 가진 더 높은 IV를 이어받습니다.
- 재료 포켓몬이 들고 있던 아이템은 합성 후 플레이어에게 돌아옵니다.
- GUI 입력과 미지급 결과는 플레이어 데이터에 함께 저장됩니다. 접속이 끊기거나 서버가 비정상 종료돼도 재접속할 때 자동으로 돌려받습니다.
- 인벤토리 공간이 부족하면 남은 아이템은 플레이어 위치에 떨어집니다.

명령어 권한은 첫 실행 때 생성되는 `config/pokefusion.json`에서 설정할 수 있습니다.

```json
{
  "commandPermissionLevel": 0
}
```

`0`은 모든 플레이어가 사용할 수 있다는 뜻이며 `0~4`만 허용됩니다. 설정 변경은 게임 또는 서버를 다시 시작한 뒤 적용됩니다. 설정 파일이 손상되거나 권한 레벨이 범위를 벗어나면 파일은 덮어쓰지 않고 기본값 `0`으로 실행합니다.

Minecraft 1.21.1, Cobblemon 1.7.3, Fabric Loader 0.19.3 이상, Fabric API, Fabric Language Kotlin과 PokemonToItem 0.2.0 이상이 필요합니다. 직접 검증한 PokemonToItem 버전은 0.2.0이며, 그보다 높은 버전은 같은 `PTI_NBT` 저장 형식을 유지하는 범위에서 허용합니다.
