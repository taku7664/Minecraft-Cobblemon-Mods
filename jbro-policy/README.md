# jbro Policy

jbro 포켓몬 서버에 적용하는 정책과 다듬기 기능을 하나로 모은 Fabric 모드입니다. 예전 서버의 `cobblemon-server-policy`, `cobleserver-legendary-policy`, `minecraft-policy`와 전설 스폰 데이터팩을 이 모드로 합쳤습니다.

- Mod ID: `jbro_policy`
- 실행 환경: 서버와 클라이언트 모두 필요
- 필요 모드: Fabric API, Fabric Language Kotlin, Cobblemon 1.8.1
- 선택 모드: More Cobblemon Contents: League Challenge(채팅 등급), Cobblenav(`/pokenav`)
- 설정 파일: `config/jbro-policy.json`
- 새 서버를 열 때 맞출 설정: [docs/SERVER_OPEN_CHECKLIST.md](docs/SERVER_OPEN_CHECKLIST.md)

## 광장

`/plaza enter`로 광장 차원(`jbro_policy:plaza`)에 가고, `/plaza exit`로 들어오기 전 위치에 돌아옵니다.

- 이동 대기시간과 피해 후 대기시간은 없습니다. 포켓몬 배틀 중에는 오갈 수 없습니다.
- 복귀 위치는 월드 데이터에 저장되므로 광장에서 접속을 끊어도 나중에 돌아갈 수 있습니다. 복귀 위치가 없거나 원래 차원이 사라졌다면 스폰 지점으로 보냅니다.
- 광장 아래로 떨어지거나 치명적인 피해를 받으면 원래 위치로 돌려보냅니다.
- 처음 열린 광장에는 착지 지점 아래에 9×9 석재 벽돌 발판을 깝니다. 착지 좌표는 설정 파일의 `plaza`에서 바꿉니다.
- 광장 바이옴(`jbro_policy:plaza`)에는 비가 오지 않고 몹이 스폰되지 않습니다. 광장 바이옴이 생기기 전에 만들어진 광장 청크는 서버 시작 때 한 번 광장 바이옴으로 바꿉니다(청크 X/Z −24~23).

### 광장 보호

OP(권한 2 이상)가 아닌 플레이어에게 적용합니다.

| 막는 것 | 허용하는 것 |
| --- | --- |
| 블록 부수기와 설치 | 음식 먹기, 볼 던지기 같은 아이템 사용 |
| 아이템을 블록에 쓰기(괭이질, 뼛가루, 부싯돌, 스폰 알 등) | 문, 상자, PC, 회복장치 같은 블록 사용 |
| 양동이 쓰기 | 포켓몬과 NPC 상호작용 |
| 엔티티 공격, 갑옷 거치대·액자 조작 | |

광장 안의 생명체는 피해를 받지 않습니다(OP의 공격 제외). 폭발, 불 번짐, 유체 흐름, 피스톤은 광장의 블록을 바꾸지 못합니다.

## 야생 포켓몬

- 야생 포켓몬의 IV를 구간 가중치로 뽑습니다. 기본값은 0~9가 20, 10~19가 45, 20~29가 25, 30~31이 10입니다.
- 야생 스폰, 화석 복원, `/givepokemon`, `/spawnpokemon`으로 생긴 포켓몬은 30% 확률로 숨겨진 특성을 받습니다.

## 편의 기능

- **첫 접속 키트:** 처음 접속한 플레이어에게 몬스터볼 20개와 상처약 10개를 주고 환영 메시지를 보냅니다. 이 모드를 넣기 전에 접속한 적이 있는 플레이어는 받지 않습니다.
- **`/pokenav`:** 포켓내비 아이템 없이 Cobblenav의 포켓내비 화면을 엽니다. Cobblenav의 `/pokenav` 하위 명령도 그대로 쓸 수 있습니다.
- **`/release <슬롯>`:** 파티 포켓몬을 놓아줍니다. 채팅의 [예]를 2분 안에 눌러야 확정되고, 마지막 포켓몬은 놓아줄 수 없습니다.
- **포켓몬 아이템 우클릭 복원:** PokemonToItem으로 만든 포켓몬 아이템을 들고 우클릭하면 `/itemtopoke`처럼 포켓몬으로 되돌립니다. 파티가 가득 찼다면 PC로 보내고, 아이템은 한 개만 사라집니다. `/itemtopoke`의 OP 권한 설정과 관계없이 누구나 쓸 수 있습니다.
- **포케스낵:** 한 번도 쓰지 않은 포케스낵을 부수면 포케스낵 아이템으로 돌려받습니다.
- **레시피:** 석탄 + 부싯돌 → 화약, 다이아몬드 4 + 석영 블록 4 + 네더라이트 주괴 → 네더의 별 레시피를 추가합니다.

## 전설 포켓몬

전설·환상·전설급 패러독스 100종의 스폰 조건, 필요 등급, 엔트리 조건, 등장 대사는 [docs/LEGENDARY_SPAWNS.md](docs/LEGENDARY_SPAWNS.md)에 있습니다.

- **내 전설:** 전설은 불러낸 플레이어만 배틀하거나 잡을 수 있습니다. 포케스낵으로 나온 전설은 포케스낵을 설치한 플레이어의 것이고, 설치한 사람이 접속해 있을 때만 나옵니다.
- **종마다 한 마리:** 야생에서 직접 잡은 기록만 남고, 교환이나 PokemonToItem으로 받은 포켓몬은 기록되지 않습니다. 이미 잡은 전설은 그 플레이어 주변에 스폰되지 않고 포켓내비 스폰표에서도 빠집니다.
- **엔트리 조건:** 32종은 파티에 특정 포켓몬이 있어야 스폰됩니다. 예를 들어 뮤츠는 파티에 뮤가 있어야 나옵니다. 포켓내비 스폰표에도 같은 조건이 적용됩니다.
- **등급 제한:** 하이퍼볼 등급은 일반 전설, 마스터볼 등급은 환상(아르세우스 제외), 챔피언은 전부 잡을 수 있습니다. 등급이 모자라면 스폰과 배틀은 되지만 포획이 실패합니다. League Challenge가 없으면 이 제한은 꺼집니다.
- **알림:** 전설이 스폰되면 종마다 다른 등장 대사와 함께 "뮤츠가 ○○ 근처에 나타났습니다!"를 서버 전체에 알립니다. 이름은 닉네임을 따르고 좌표는 알리지 않습니다.
- **`/legends <포켓몬> [플레이어]`:** 그 전설을 직접 잡았는지와 필요 등급, 엔트리 조건을 보여 줍니다. 포켓몬은 영어 ID로 입력하며 자동완성됩니다. 플레이어를 빼면 자기 자신입니다.
- **`/legends reset <포켓몬> <플레이어>`:** OP 전용입니다. 롤백 등으로 꼬인 포획 기록을 지웁니다.
- **`/spawnpokemonfor <플레이어> <포켓몬>`:** OP 전용입니다. 대상 플레이어 앞에 포켓몬을 스폰합니다. 전설이면 대상이 주인이 되고 알림이 나가며, 레벨을 지정하지 않으면 그 전설의 야생 스폰 레벨 범위에서 고릅니다. 대상이 이미 잡았거나 등급이 모자라 포획할 수 없으면 명령을 친 사람에게 알려 줍니다. Cobblemon의 `/spawnpokemon`으로 부른 전설은 주인이 없어 누구나 배틀하고 잡을 수 있습니다.

## 채팅

플레이어 채팅은 리그 챌린지 등급을 앞에 붙인 형식으로 보입니다.

```
[볼 아이콘 등급 이름] 닉네임: 대화
```

| 리그 등급 | 아이콘 | 등급 이름 색 |
| --- | --- | --- |
| 몬스터볼 (배지 0~2개) | 몬스터볼 | 빨강 |
| 수퍼볼 (배지 3~4개) | 수퍼볼 | 파랑 |
| 하이퍼볼 (배지 5~7개) | 하이퍼볼 | 노랑 |
| 마스터볼 (배지 8개) | 마스터볼 | 보라 |
| 챔피언 | 마스터볼 | 금색 |

플레이어 채팅에만 이 모드의 채팅 형식(`jbro_policy:chat`, `이름: 대화`)을 씁니다. 귓속말과 시스템 메시지, 머리 위 이름표, 탭 목록은 바뀌지 않습니다. League Challenge가 설치되지 않았거나 리그 카탈로그가 아직 로드되지 않았다면 `닉네임: 대화`로만 보입니다.

아이콘은 Cobblemon의 볼 아이템 텍스처를 `jbro_policy:rank_icons` 폰트 글리프로 불러와서 그립니다. 따라서 이 모드가 없는 클라이언트에서는 아이콘 자리에 빈 글자가 보입니다.

## 공지

`[공지] 내용` 형식으로 서버 전체에 공지합니다. `[공지]`는 파란색입니다.

- **명령:** `/announce <내용>` 또는 `/공지 <내용>`. 권한 레벨 3 이상(킥·밴과 같은 운영 권한)이 필요하고, 서버 콘솔에서도 쓸 수 있습니다.
- **API:** 다른 모드에서는 `jbro.cobblemon.policy.api.Announcements.broadcast(server, message)`를 호출합니다.

## 문의

플레이어가 운영자에게 문의를 보내면 설정한 메일 주소로 전달됩니다. 메일에는 닉네임, 아이디, UUID, 경로(위키·명령어), 시각, 사유가 들어갑니다.

- **명령:** `/문의 <사유>` 또는 `/inquiry <사유>`. 모든 플레이어가 쓸 수 있습니다.
- **위키:** 서버 위키의 문의하기 페이지에서 보냅니다. `/mcc wiki` 링크의 토큰으로 보낸 사람을 확인하므로 다른 사람 이름으로는 보낼 수 없습니다.
- **제한:** 사유는 100자 이내이고, 한 사람이 5분에 한 번 보낼 수 있습니다. 위키와 명령어가 같은 대기시간을 씁니다. 메일 발송이 실패하면 대기시간이 걸리지 않습니다.
- **설정:** `config/jbro-policy-mail.json`에 발송 계정(SMTP)과 받는 주소를 적습니다. 비어 있으면 문의 기능이 꺼지고 플레이어에게 그렇게 안내합니다. 비밀번호가 들어가는 파일이라 주 설정 파일과 분리했습니다.

```json
{
  "host": "smtp.gmail.com",
  "port": 465,
  "security": "ssl",
  "username": "보내는계정@gmail.com",
  "password": "앱 비밀번호",
  "from": "보내는계정@gmail.com",
  "to": "받을주소@example.com"
}
```

Gmail로 보낸다면 Google 계정에서 2단계 인증을 켜고 "앱 비밀번호"를 만들어 `password`에 넣습니다. 계정 비밀번호는 쓸 수 없습니다. `security`는 `ssl`(보통 465), `starttls`(보통 587), `none`(같은 컴퓨터의 중계 서버 전용) 중 하나입니다.

## 로그

`jbro.cobblemon.policy.api.PlayerLog.send(player, message, color)`로 한 플레이어에게 색을 지정한 메시지를 보냅니다. 색을 빼면 회색입니다. 문의 대기시간 안내("문의는 N분 후에 다시 보낼 수 있습니다.")는 붉은색으로 보냅니다.

## 안내

접속자가 있으면 30초마다 `[안내] 내용`을 서버 전체에 보냅니다. `[안내]`는 노란색이고, 내용은 목록에서 무작위로 고르되 같은 안내가 연달아 나오지 않습니다.

- **목록과 간격:** 설정 파일의 `tips`와 `tipIntervalSeconds`에서 바꿉니다. 간격을 0으로 하면 안내가 꺼집니다. 설정은 서버를 재시작해야 반영됩니다.
- **API:** 다른 모드에서는 `jbro.cobblemon.policy.api.Tips.add(message)`로 목록에 안내를 더하고, `Tips.broadcast(server, message)`로 즉시 보냅니다.

## 내장 데이터팩

아래 두 팩은 기본으로 켜지며, 월드마다 `/datapack disable`로 끌 수 있습니다.

- **`jbro_policy:legendary_spawns`:** 전설·환상·전설급 패러독스 100종이 `ultra-rare` 버킷으로 자연 스폰됩니다. 울트라비스트는 빠져 있고, Myths & Legends가 설치되어 있으면 꺼집니다. 예전 서버의 Cobblemon 1.7.3용 스폰표를 1.8 형식(`spawnablePositionType`)으로 옮겼습니다.
- **`jbro_policy:no_stat_candy_l_xl`:** 캠프 냄비의 능력치 사탕 L/XL 레시피 12개를 막습니다.

## 설정

`config/jbro-policy.json`이 없으면 기본값으로 만듭니다. 파일 내용이 잘못되었다면 파일은 그대로 두고 그 실행에서만 기본값을 씁니다.

```json
{
  "plaza": { "x": 0.5, "y": 80.0, "z": 0.5, "yaw": 0.0, "pitch": 0.0 },
  "wildHiddenAbilityRate": 30,
  "wildIvDistribution": {
    "enabled": true,
    "ranges": [
      { "min": 0, "max": 9, "chance": 20.0 },
      { "min": 10, "max": 19, "chance": 45.0 },
      { "min": 20, "max": 29, "chance": 25.0 },
      { "min": 30, "max": 31, "chance": 10.0 }
    ]
  },
  "tipIntervalSeconds": 30,
  "tips": ["/plaza enter로 광장에 갈 수 있습니다. 돌아올 때는 /plaza exit를 입력하세요.", "..."]
}
```

## 예전 월드에서 옮길 때

예전 광장은 `world/dimensions/cobblemon_policy/plaza`에 있습니다. 새 월드의 `dimensions/jbro_policy/plaza`로 옮기면 서버 시작 때 바이옴 마이그레이션이 한 번 실행됩니다. 예전 모드의 복귀 위치와 첫 접속 키트 기록은 옮겨지지 않습니다.

## 빌드와 확인

```powershell
.\gradlew.bat --offline --no-daemon --configure-on-demand :jbro-policy:build
```
