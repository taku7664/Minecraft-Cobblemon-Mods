# 배틀타워 세션 기믹 선택 결정

- Status: shared
- Effective: 2026-08-18
- Updates: [`CONTENT_SCOPE.md`](../architecture/CONTENT_SCOPE.md)의 배틀타워 주요 기믹 배치와 구현 전 결정 게이트 2
- Updates: [`TOWER_OPPONENT_DATA.md`](../catalog/TOWER_OPPONENT_DATA.md)의 상대 프로필 선택 조건

## 1. 결정

- 새 배틀타워 도전을 시작하는 플레이어는 첫 전투 전에 `MEGA`, `DYNAMAX`, `TERA` 중 하나를 **MUST** 선택한다.
- 선택된 주요 기믹은 해당 배틀타워 실행 세션 전체에 **MUST** 고정된다.
- 플레이어는 세션을 포기하거나 정상 종료하고 새 세션을 만들기 전까지 선택된 주요 기믹을 변경해서는 **MUST NOT** 된다.
- 플레이어와 NPC는 같은 선택 기믹 규칙을 **MUST** 적용받고, 각 진영은 해당 기믹을 한 전투에서 최대 한 번만 **MUST** 사용할 수 있다.
- 가방 아이템은 선택 기믹과 관계없이 배틀타워 전투에서 **MUST NOT** 사용할 수 있다.

## 2. 세션 경계

- 기믹 미선택 상태에서는 팀을 확정하거나 첫 전투를 시작해서는 **MUST NOT** 된다.
- 첫 전투가 시작되기 전의 팀 선택 단계에서는 기믹 선택을 바꿀 수 **MAY** 있다.
- 첫 전투가 성공적으로 생성된 시점부터 기믹 선택은 세션 고정값이 된다.
- 활성 세션과 선택 기믹을 월드 NBT에 저장하거나 서버 재시작 뒤 복구하지 않는다. 기록 저장 범위는 승패·연승·진행도·최고 기록으로 한정한다.

## 3. 상대 풀

- 상대 카탈로그 스키마 2 프로필은 자신이 속한 `mechanic_id`를 `mega`, `dynamax`, `tera` 중 정확히 하나로 **MUST** 선언한다.
- 상대 선택기는 현재 랭크, 싱글·더블 형식, 상대 종류와 세션 기믹이 모두 일치하는 프로필만 **MUST** 후보로 사용한다.
- 일치하는 프로필이나 합법 팀이 없으면 다른 기믹의 풀로 대체하지 않고 전투 시작을 실패로 닫아야 **MUST** 한다.
- 포켓몬 세트는 검증된 공통 세트로 재사용할 수 **MAY** 있지만, 실제 트레이너 프로필 풀은 기믹별로 구분돼야 **MUST** 한다.
- 기존 스키마 1 카탈로그는 전환 기간 동안 읽을 수 **MAY** 있지만 기믹 미지정 레거시로 취급하며 새 세션 상대 선택에 사용해서는 **MUST NOT** 된다.

## 4. 대체된 결정 게이트

기존의 “랭크별 `NONE`, `MEGA`, `DYNAMAX`, `TERA` 배치” 결정 게이트는 이 문서 적용일부터 사용하지 않는다. 새 세션 선택지에는 `NONE`과 Z기술을 두지 않는다. 랭크가 기믹을 자동 선택하지 않으며, 정확한 기믹별 트레이너 프로필과 포켓몬 세트 데이터는 별도 승인 후 작성한다.

## 5. 검토했으나 채택하지 않은 방식

- 랭크가 올라갈 때 기믹을 자동 변경하는 방식은 한 세션에서 선택 규칙이 바뀌고 플레이어 준비물이 무효화될 수 있어 채택하지 않았다.
- 일치하는 기믹 풀이 없을 때 일반 풀로 폴백하는 방식은 사용자가 선택한 규칙과 실제 상대 구성이 달라지므로 채택하지 않았다.
- `MEGA` 선택에 Z기술을 함께 묶는 방식은 현재 범위에서 제외했다.
- 기믹 선택을 전투마다 다시 받는 방식은 세션 정체성과 연속 도전 준비를 깨므로 채택하지 않았다.
