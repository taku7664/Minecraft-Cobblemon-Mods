## 1. 화면 계약

- 공통 첫 탭의 사용자 표시 이름은 `홈`이어야 한다(MUST). 내부 `BattleHubContent.SHOP` ordinal은 부분 배포 호환 때문에 바꾸지 않는다(MUST NOT).
- 고정 탭 순서는 `홈 → PvP → 배틀타워 → 배틀팩토리 → 보스 레이드`여야 한다(MUST).
- 상단바·실제 BP·X·탭 좌표는 콘텐츠를 바꿔도 고정하고, 홈 본문만 아래 구조로 그려야 한다(MUST).
  - 좌측 상단: 현재 플레이어의 3D 캐릭터 모델과 닉네임
  - 좌측 하단: 배틀타워 싱글/더블 리더보드와 내부 세로 스크롤
  - 우측 전체: 축소된 BP 상점과 독립 세로 스크롤
- 캐릭터 모델은 마우스를 따라보지 않고 정면을 유지해야 하며(MUST NOT), 월드 시간에 따라 기본 유휴 애니메이션이 진행되어야 한다(MUST).
- 상품 카드는 실제 아이템 아이콘·이름·가격을 표시하고 Minecraft 기본 아이템 툴팁을 유지해야 한다(MUST).
- 상점과 리더보드는 각각 휠과 드래그 손잡이를 사용하는 독립된 세로 오프셋을 가져야 한다(MUST). 한쪽 스크롤이 다른 목록을 움직여서는 안 된다(MUST NOT).
- 화면 밖 행과 상품은 렌더·클릭 대상에서 제외하고 각 뷰포트 경계에서 잘라야 한다(MUST).

## 2. 리더보드 계약

- 첫 홈 리더보드는 배틀타워 `SINGLE`과 `DOUBLE`만 제공한다(MUST). 초기 PvP에는 시즌·레이팅을 만들지 않는다(MUST NOT).
- 형식별 정렬은 다음 값을 차례대로 내림차순 비교해야 한다(MUST).
  1. 최고 랭크 `highest_rank`
  2. 현재 랭크 진행 `rank_progress`
  3. 누적 승리 `totalWins`
- 위 세 값이 모두 같으면 같은 순위를 부여한다(MUST). 다음 순위는 경쟁 순위 방식으로 건너뛴다. 예: `1, 1, 3`.
- 동률 행의 표시 순서는 대소문자를 무시한 플레이어 이름, UUID 순으로 안정화해야 한다(SHOULD). 이 표시 순서는 동률 순위를 깨지 않는다(MUST NOT).
- 서버 프로필 이름을 찾지 못하면 UUID 앞 8자를 표시할 수 있다(MAY).
- 서버는 형식별 최대 200행을 전송한다(MUST). 저장소의 나머지 기록을 삭제하거나 변경해서는 안 된다(MUST NOT).

## 3. 네트워크와 부분 배포

- 기존 상점 상태 패킷은 수정하지 않는다(MUST NOT). 리더보드는 별도 `home_leaderboard_state` S2C payload로 보낸다(MUST).
- 서버는 클라이언트가 새 payload를 수신할 수 있을 때만 리더보드를 전송해야 한다(MUST).
- 새 클라이언트가 구 서버에 연결되면 홈 레이아웃과 상점은 기존 상점 상태로 열리고 리더보드는 로딩 상태로 남을 수 있다(MAY). 이를 실제 기록 없음으로 표시해서는 안 된다(MUST NOT).

## 4. 폐기와 검증 상태

- 2026-08-19부터 전체 화면 가로 상점과 하단 가로 스크롤 계약은 종료한다. 후속 버전에서 같은 가로 상점 화면을 다시 제공하지 않는다(MUST NOT).
- 가로 상점 결정 문서는 구현 이력만 보존하며 활성 GUI 계약으로 참조하지 않는다.
- 구현 전 새 패널·세로 스크롤·리더보드 타입이 없어 계약 테스트가 컴파일 실패하는 것을 확인했다.
- 구현 후 본체 단위 테스트 455개, 모듈 빌드, 한·영 JSON 파싱과 JDK 21 JAR 검증이 통과했다. 빌드 SHA-256은 `667F789DBCAEC4D4BC2B3417EDB44B464D735CB6BD7158CFFA972DB76738B106`이다.
- 적용 확인을 시작했을 때 `cobblemon-dev`와 `dev-server`의 본체 JAR은 이미 빌드 SHA-256 `667F789DBCAEC4D4BC2B3417EDB44B464D735CB6BD7158CFFA972DB76738B106`과 일치해 중복 복사하지 않았다. `dev-server/run.bat`으로 기동한 Java PID 31772가 `127.0.0.1:25566`, `[13:35:52] Done (1.152s)`에 도달했고 타워·팩토리·44품목 상점 카탈로그를 로드했다. 서버 ERROR 9개는 기존 Cobblemon 데이터픽서 7개와 README 경로 2개이며 MBC 실패 일치는 0개다. 이후 시작한 `cobblemon-dev`도 새 JAR보다 늦게 기동해 `cobblemon_more_battle_content` 리소스를 로드했다. 실제 모델 방향·유휴 애니메이션, 두 목록의 휠·드래그, 툴팁, 구매와 리더보드 데이터는 게임 안에서 검증하지 않았다.

## 5. 폐기한 대안

- **상점만 전체 본문에 유지:** 홈에서 캐릭터와 기록을 함께 확인하려는 목적을 충족하지 못해 폐기했다.
- **좌우 화면 전환 또는 페이지 버튼:** 사용자가 한 화면에서 정보를 비교할 수 없고 기존 페이지형 탐색 문제를 되풀이하므로 폐기했다.
- **PvP 승수 리더보드 즉시 추가:** 시즌·레이팅 계약 없이 단순 승수를 경쟁 순위처럼 보이게 할 수 있어 첫 범위에서 제외했다.
