## 1. 루트 공통 상단바와 탭

- `/mbc open`, 배틀타워, 배틀팩토리와 PvP 룸 목록은 같은 크기와 좌표의 상단바·탭을 사용해야 한다(MUST).
- 상단바 왼쪽에는 `Cobblemon: More Battle Content`, 오른쪽에는 서버에서 받은 현재 플레이어 BP와 X를 표시해야 한다(MUST).
- 탭을 바꿀 때는 상단바·탭의 위치와 크기를 유지하고 아래 콘텐츠 영역만 교체해야 한다(MUST). 콘텐츠별 셸 너비를 탭 좌표 계산에 사용해서는 안 된다(MUST NOT).
- 루트 X와 ESC는 모두 MBC GUI 전체를 닫고 게임으로 돌아가야 한다(MUST).
- 배틀타워의 BP 중복 표시는 제거하고, 단계별 주 행동은 보라색 상태 패널 안에 배치해야 한다(MUST).

## 2. PvP 룸 전용 화면

- 룸 목록에서 방을 선택하면 루트 고정 탭 아래에 끼우지 않고 더 넓은 별도 룸 화면을 열어야 한다(MUST).
- 룸 화면의 X와 ESC는 모두 현재 룸 화면만 닫고 PvP 룸 목록으로 돌아가야 한다(MUST).
- X와 ESC는 서버의 `Leave` 의도를 보내거나 룸 회원 상태를 바꾸면 안 된다(MUST NOT). 실제 퇴장은 별도 `방 나가기` 행동만 수행한다(MUST).
- 룸 화면을 닫아 목록을 보는 동안 다른 참가자의 룸 상태 갱신이 도착해도 룸 화면을 강제로 다시 열어서는 안 된다(MUST NOT). 현재 클라이언트가 보낸 생성·입장 요청의 응답만 목록 위에 룸 화면을 열 수 있다(MUST).

## 3. 설정 그룹

- 공개·비공개는 `공개 범위`, 싱글·더블은 `배틀 형식`, 메가·다이맥스·테라·Z기술은 `허용 기믹` 그룹으로 시각적으로 분리해야 한다(MUST).
- 각 그룹은 제목과 작은 선택 버튼을 가져야 하며 여덟 버튼을 구분 없이 한 줄로 나열해서는 안 된다(MUST NOT).
- 좌·우 모델, 관전자, 관전석 이동, 초대, 방장 양도, 시작과 실제 나가기의 기존 역할 분리는 유지한다(MUST).

## 4. 채택하지 않은 안

- 화면마다 별도 셸로 탭을 계산하는 안은 탭 전환 때 위치가 움직여 폐기한다.
- PvP 룸에도 루트 탭을 반복하는 안은 룸 정보 공간을 줄이고 X/ESC의 복귀 계층을 모호하게 만들어 폐기한다.
- 서버 push에 `requestId`가 있다는 이유만으로 룸을 다시 여는 안은 다른 참가자의 요청 ID도 함께 전파될 수 있어 폐기한다. 클라이언트가 보관한 자기 생성·입장 요청 ID와 일치해야 한다.
