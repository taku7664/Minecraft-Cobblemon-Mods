# 배틀타워 상대 트레이너 데이터 출처 결정

> **2026-09-27 정리 메모:** 3·4절의 랭크 ID 기반 단일 카탈로그는 현재 데이터가 아니다. 현재 타워 데이터는 트레이너·출전 풀·대전 조건·포켓몬 세트(스키마 4)로 나뉜다. 상세는 [인덱스의 불일치 표](../README.md#현재-코드와-다른-조항)를 본다.

## 1. 결정

- 배틀타워의 일반·보스 NPC 팀은 MBC 전용 신규 데이터로 작성해야 한다(MUST).
- 소드·실드 배틀타워의 실제 트레이너 팀을 그대로 복제하지 않아야 한다(MUST).
- 소드·실드뿐 아니라 배틀프런티어, 배틀서브웨이, 배틀하우스, 배틀트리 등 여러 본가 배틀 시설의 공개 규칙, 난도 곡선, 전략 역할과 풀 구성 패턴을 참고할 수 있다(MAY).
- 다른 모드의 트레이너 데이터, 번역, 자산과 디컴파일 구조는 복사하지 않아야 한다(MUST).
- 싱글과 더블은 같은 종 목록을 무조건 공유하지 않고 형식별 역할·시너지를 검증해야 한다(MUST).

## 2. 채택할 설계 패턴

- 트레이너 프로필은 출현 랭크 범위, 전투 형식, 상대 종류, AI skill과 전략 테마를 소유한다(SHOULD).
- 각 프로필은 고정 한 팀보다 검증된 포켓몬 세트 풀을 소유하고, 서버가 종·지닌도구 중복 금지와 형식별 필요 마릿수를 검증한 후 3마리 또는 4마리를 선택해야 한다(SHOULD).
- 인접 난도 구간은 일부 프로필을 가중치로 겹치게 할 수 있다(MAY). 단, 하위 랭크에 상위 랭크의 완성형 세트를 조기 노출하지 않아야 한다(MUST).
- 티어 마지막과 MAX 주기 보스는 일반 풀과 분리된 프로필을 사용해야 한다(MUST).

## 3. 확정된 스키마 1 계약

- 카탈로그는 모드 내장 datapack JSON으로 제공해야 한다(MUST).
- 루트는 `schema_version`, `catalog_id`, `profiles`, `sets`를 소유해야 한다(MUST).
- 프로필은 기존 랭크 ID, 싱글·더블 형식, 일반·티어 보스·MAX 보스 종류, 가중치, Cobblemon AI skill, 전략 테마와 세트 풀을 소유해야 한다(MUST).
- 포켓몬 세트는 안정 ID, 세트 티어, 종·선택형 폼·선택형 특성·성격·선택형 지닌 도구·1~4개 기술과 여섯 능력치 IV·EV를 소유해야 한다(MUST).
- 로더는 알 수 없는 필드, 지원하지 않는 스키마, 중복 ID, 잘못된 값과 누락 참조를 거절해야 한다(MUST).
- 프로필 후보 풀은 최소 6세트여야 하며 싱글 3마리 또는 더블 4마리의 종·비어 있지 않은 지닌 도구 중복 없는 조합을 최소 하나 만들 수 있어야 한다(MUST).
- 재로드 실패는 직전 정상 카탈로그 스냅샷을 교체하지 않아야 한다(MUST).
- 기믹 배치는 상대 카탈로그가 아니라 본체 전투 규칙이 소유해야 한다(MUST).

## 4. 첫 데이터 범위

첫 데이터는 랭크 1~3 일반전, 싱글 프로필 2개와 더블 프로필 2개, 프로필당 후보 6세트로 확정했다. 빡대리님이 2026-08-18에 실제 24세트의 종·기술·특성·도구·성격·IV·EV와 한·영 프로필 이름을 확인했으며, 승인된 값만 `mbc_core.json`과 언어 리소스에 작성했다.

## 5. 채택하지 않은 대안

- 소드·실드의 실제 NPC 팀 복제는 MBC 전용 콘텐츠라는 결정과 충돌하고 이후 기믹·세대 확장을 제한하므로 채택하지 않는다.
- 외부 배틀타워 모드의 팀 데이터 이식은 허가·출처 경계와 독립 구현 원칙을 훼손하므로 채택하지 않는다.
- 트레이너마다 한 팀만 고정하는 방식은 반복 전투의 변화 폭이 작고 싱글·더블 형식별 검증을 분리하기 어려우므로 기본 모델로 채택하지 않는다. 보스만 별도 고정 또는 제한 풀을 사용할 수 있다(MAY).

## 6. 공개 참고 근거

- 배틀서브웨이: 트레이너별 후보 풀에서 싱글 3마리·더블 4마리를 구성하고 상위 코스에서 완성형 세트를 사용한 패턴
- 신오 배틀프런티어: 진행에 따라 트레이너와 IV 난도가 상승하는 패턴
- 배틀하우스: 진행 구간별 트레이너·세트 단계와 인접 구간의 일부 겹침 패턴
- 배틀트리: 일정 주기의 특별 트레이너와 별도 후보 풀 패턴

이 근거는 공개 동작의 설계 패턴만 설명한다. 실제 팀·번역·자산은 새 데이터의 원본으로 사용하지 않는다(MUST).
