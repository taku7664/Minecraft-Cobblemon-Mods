# Battle UI 남색·청록 표면 적용

- 적용일: 2026-09-27
- 독자: Battle UI 구현자와 빡대리님
- 기준: 사용자가 제공한 UI Kit 이전/이후 비교 이미지의 오른쪽 스타일
- 상태: 구현 및 단위 검증 완료, 실제 전투 검증은 아래 기록으로 구분

## 적용 계약

Battle UI는 짙은 남색 표면, 청록 외곽선, 작은 대각선 모서리와 역할별 버튼 강조를 사용한다. 중앙 대사창과 TAB 정보창의 큰 셸, 명령 버튼, 기술 버튼, 기술·포켓몬 툴팁에 같은 표면 렌더러를 적용한다.

- 큰 셸은 네 모서리 챔퍼와 어두운 세로 그라데이션을 사용한다(SHOULD).
- 싸운다는 청록, 포기·도주는 붉은색, 포획은 보라색 강조를 사용한다(SHOULD). 보조 명령과 내부 정보 행은 직사각형을 사용할 수 있다(MAY).
- 기술 버튼은 기술명·타입 아이콘·분류 아이콘·PP·사용 불가 상태를 유지해야 한다(MUST). 타입색은 테두리와 타입 정보로 식별한다.
- 키보드 포커스와 마우스 호버는 기존 입력 소유권을 따르고, 초점 표시는 실제 버튼 모양을 따라야 한다(MUST).
- 전투 대사 큐, 확정·취소 키, 클릭 영역, 명령 배치, TAB 모달 깊이, 공개 정보 제한과 여섯 칸 랭크 표시는 유지해야 한다(MUST).
- 작은 챔퍼는 장식이며 클릭 영역은 기존 직사각형을 유지한다. 교체·대상 선택의 Cobblemon 원본 포켓몬 타일과 기믹 아이콘은 이번 표면 변경 대상에 포함하지 않는다.

## 구현 경계

`BattleUiTheme`에 색과 표면 역할을 모으고 `BattleSurface`에서 채움 두 색·테두리 굵기·모서리 컷·적용 모서리·배경 불투명도를 분리한다. 테두리 굵기 0은 무테, 채움 알파 0은 채움 없음이다. 렌더러는 픽셀을 중복 채우지 않아 반투명 테두리 아래에 배경색이 겹치지 않는다.

이 모듈의 Yarn `DrawContext`에 맞춘 내부 어댑터다. UI Kit의 Mojang 매핑 클래스를 직접 참조하거나 MBC 런타임 의존성을 추가하지 않는다. 배포 형태를 공용 필수 JAR로 확정하는 변경은 포함하지 않는다.

한·영 문자열은 기존 번역을 그대로 사용한다. 긴 명령·기술 이름은 버튼 안쪽 폭에 맞춰 축척을 줄인다. 현재 ModMenu 설정 화면과 키 설정을 유지하며 이번 시각 변경으로 새 저장 설정은 추가하지 않는다.

## 검증

- `:cobblemon-battle-ui:unitTest :cobblemon-battle-ui:build`: 116개 테스트 통과, 빌드 성공.
- 새 순수 테스트는 선택 모서리, 기존 알파와 불투명도 곱, 그라데이션 양끝·중간 알파를 확인한다.
- 첫 컴파일의 Cobblemon 화면 불투명도 `Double`/렌더러 `Float` 불일치는 명시적 변환으로 수정했다.
- 실제 전투 화면·물리 입력·배포 증거는 검증 후 이 문서에 추가한다. 빌드 성공으로 대체하지 않는다.
