# LumaVale

LumaVale는 선을 두르거나 화면을 만화처럼 평면화하지 않고, 햇빛과 그림자, 밤의 광원 분위기만 부드럽게 바꾸는 Iris 쉐이더팩입니다.

## 목표

- 낮에는 크림색 햇빛과 푸른 환경광이 함께 보이는 밝은 초원 분위기
- 해질녘에는 복숭아색 직사광과 길고 부드러운 그림자
- 밤에는 차가운 하늘빛과 따뜻한 블록 광원을 분리
- 어두운 부분이 검게 뭉개지지 않는 낮은 대비
- 색을 번지게 만들지 않는 약한 블룸
- 낮은 지형을 따라 두께감 있게 흐르는 지면 물안개
- 건조·강수·설원 생물군계에 맞춰 부드럽게 달라지는 안개색
- 지하 깊이와 하늘광에 따라 자연스럽게 짙어지는 동굴 안개
- 외곽선, 셀 셰이딩, 과한 반사 효과는 사용하지 않음

## 안개 품질

지면 물안개는 화면 위에 평면을 덧씌우지 않습니다. 카메라에서 보이는 지점까지의 월드 공간을 여러 구간으로 나눠 높이와 움직이는 밀도 변화를 누적하므로, 지형과 생물이 안개 속에 잠기는 깊이 차이가 보입니다.

- `가벼움`: 픽셀당 2회 표본
- `포근함`: 픽셀당 4회 표본
- `고품질`: 픽셀당 6회 표본

생물군계 전환은 Iris가 제공하는 현재 카메라 위치의 강수 분류를 사용합니다. 따라서 멀리 보이는 서로 다른 생물군계를 픽셀별로 나누는 방식은 아니며, 생물군계 경계를 통과할 때 화면 전체의 안개색이 서서히 바뀝니다.

## 실행 환경

- Minecraft 1.21.1
- Iris 1.8.8
- Sodium 0.6.13
- OpenGL 3.3 compatibility profile

Rounding-Block과는 독립된 쉐이더팩입니다. Rounding-Block이 없어도 사용할 수 있고, 함께 사용하면 둥근 지형 메시가 실제 그림자 패스에도 포함됩니다.

## 빌드

```powershell
.\lumavale\build.ps1
```
