# Simple MyRoom

Minecraft 1.21.1 Fabric 서버에서 플레이어마다 독립된 마이룸을 만들어 주는 서버 전용 모드입니다. 기존 MyRoom 0.5.1의 방 좌표, 차원 ID, 저장 데이터를 그대로 이어받도록 만들었습니다. 클라이언트에는 설치하지 않아도 됩니다.

## 설치

`simple-myroom-1.3.0.jar`를 서버의 `mods` 폴더에 넣고 기존 `myroom-*.jar`는 제거합니다. 두 모드를 같이 넣으면 같은 차원과 저장 데이터를 동시에 다루므로 함께 사용하면 안 됩니다.

서버를 처음 실행하면 아래 두 파일이 생깁니다.

- `config/simple-myroom.json`: 명령어, 기본 공개·신뢰·차단 값, 방 크기와 바닥, 보호 범위, 방문자 상호작용, 복귀 방식
- `config/simple-myroom-messages.json`: 플레이어에게 보이는 한국어 문구

JSON이 깨졌거나 허용 범위를 벗어난 값이 있으면 그 파일을 덮어쓰지 않고 마지막으로 정상 적용된 설정을 계속 사용합니다. 관리자는 `/room reload`로 서버를 재시작하지 않고 대부분의 값을 다시 읽을 수 있습니다. 명령어 별칭은 서버 시작 때 등록되며, 이미 방이 만들어진 월드의 배치 값은 기존 방 보호를 위해 저장된 값을 우선합니다.

## 명령어

- `/room`: 내 방 정보와 도움말
- `/room enter [플레이어]`: 내 방 또는 다른 플레이어의 공개된 방으로 이동
- `/room exit`: 입장 전 위치로 복귀
- `/room public <true|false>`: 방문 공개 여부 변경
- `/room trust <플레이어>` / `/room untrust <플레이어>`: 방문자에게 건축·수확 권한을 주거나 회수
- `/room ban <플레이어>` / `/room unban <플레이어>`: 방문 차단 또는 해제
- `/room kick <플레이어>`: 현재 내 방에 있는 방문자 퇴장
- `/room active <on|off|status>`: 내 방 상시 활성화 켜기, 끄기, 상태 확인
- `/room setspawn`: 서 있는 위치와 바라보는 방향을 내 방 입장 위치로 지정
- `/room setspawn reset`: 별도 입장 위치를 지우고 기본 중앙 위치로 복원
- `/room visitors`: 현재 내 방에 있는 방문자 확인
- `/room notify <on|off>`: 방문자 입장·퇴장 알림 켜기 또는 끄기
- `/room reload`: 관리자의 JSON 설정 다시 읽기

기본 별칭으로 `/myroom`도 같은 명령을 제공합니다.

입장 명령의 기본 재사용 대기시간은 0초입니다. 필요하면 `commands.enterCooldownSeconds`로 바꿀 수 있습니다. 지정한 입장 위치나 기본 중앙 위치가 막히면 주변의 충돌 없는 좌표를 찾습니다. 탐색 범위, 바닥 필요 여부와 유체 허용 여부는 `customSpawn` 항목에서 조정할 수 있습니다.

마이룸에 들어오기 전 위치는 오버월드·네더·엔더뿐 아니라 서버에 존재하는 모든 모드 차원에서 저장됩니다. 마이룸 안에서 다른 마이룸으로 이동할 때만 기존 외부 복귀점을 유지합니다. `/room exit` 시 원래 좌표가 블록으로 막혔다면 `returnBehavior`에 지정된 범위에서 안전한 좌표를 찾고, 찾지 못하면 기본 설정상 오버월드 스폰 주변의 안전한 좌표로 이동합니다.

방문 알림은 명령어 이동뿐 아니라 포탈, 관리자 텔레포트, 차원 이동, 접속 종료로 실제 방 출입 상태가 달라진 경우에도 처리합니다. 새 방과 기존 방 모두 기본값은 알림 켜짐이며, 서버 전체 동작·신뢰 플레이어 포함 여부·방문자 목록 최대 표시 인원은 `visitorNotifications`에서 바꿀 수 있습니다.

비공개 또는 차단된 방에 다른 텔레포트 수단으로 직접 들어온 유저도 기본값에서는 즉시 복귀 처리됩니다. 관리자 방문 우회와 자동 퇴장 여부는 `access`에서 바꿀 수 있습니다.

새 방의 바닥과 전체 높이 경계는 한 틱에 모두 만들지 않습니다. 기본값에서는 틱당 최대 4096블록씩 준비하고, 완료되면 요청한 유저를 자동 입장시킵니다. 틱당 처리량, 대기열 크기, 완료 후 자동 입장과 안내 문구 여부는 `roomPreparation`에서 조정할 수 있습니다.

## 보호 범위

주인과 신뢰받은 플레이어만 블록을 설치하거나 캘 수 있습니다. 농작물은 평소처럼 자라지만 권한 없는 방문자는 수확하거나 밭을 밟아 망가뜨릴 수 없습니다. 기본 설정에서는 방문자가 빈손으로 상자, 작업대, 모루, 숫돌, 엔더 상자를 사용할 수 있습니다.

폭발의 블록 파괴, 불 번짐, 피스톤, 자연 몬스터 스폰, 방 밖 블록·엔티티 생성도 각각 JSON에서 켜고 끌 수 있습니다. 관리 권한 우회 레벨과 거부 메시지 표시 간격도 설정할 수 있습니다.

## 상시 활성화

`/room active on`을 사용하면 방의 100×100 영역과 겹치는 49개 청크가 엔티티 틱 단계로 유지됩니다. 유저가 방에 없어도 농작물, 호퍼·화로 같은 블록 엔티티, 목장 블록과 방목 포켓몬 처리가 계속됩니다. 실제 플레이어가 근처에 있는지를 별도로 검사하는 다른 모드 기능까지 대신하지는 않습니다.

이 기능은 바닐라 `/forceload` 저장 목록을 사용하지 않습니다. 유저별 선택만 `myroom_rooms` 데이터에 저장하고, 서버 시작 시 Simple MyRoom 전용 티켓을 다시 적용합니다. 기능을 끄거나 서버가 종료되면 티켓은 제거됩니다.

기본값은 꺼짐이며 `keepActive.defaultEnabled`로 바꿀 수 있습니다. `maxActiveRooms`, `maxChunksPerRoom`, 명령어 재사용 대기시간, 관리자 상한 우회, 재시작 복구와 로그 출력도 JSON에서 설정할 수 있습니다.

## 설정에서 바꿀 수 있는 주요 값

`simple-myroom.json`에는 다음 항목이 들어 있습니다.

- 첫 방의 공개 여부, 기본 신뢰·차단 플레이어 목록
- 신뢰 플레이어의 비공개 방 방문과 건축 허용 여부
- 방 크기, 방 사이 간격, 한 줄에 놓을 방 수, 바닥 높이와 블록, 경계 블록, 입장 좌표와 바라보는 방향
- 입장 재사용 대기시간, 관리자 권한 레벨, 명령어 별칭과 자동완성, 정보 화면 최대 표시 인원
- 블록 캐기·설치·사용, 엔티티 공격·사용, PvP, 펫 피해, 폭발, 불, 피스톤, 밭 밟기, 거북알 훼손, 자연 스폰, 미할당 공간 보호
- 방문자가 사용할 수 있는 블록 ID 목록과 빈손 요구 여부
- 모든 외부 차원의 정확한 좌표·시선 저장 여부, 안전한 복귀 위치 탐색 범위, 복귀 실패와 리스폰 처리 방식
- 상시 활성화 기본값, 동시 활성 방·방당 청크 상한, 재시작 복구, 관리자 우회와 로그
- 개인 입장 위치 기능, 안전 검사, 막힌 위치의 중앙 우회와 초기화 허용 여부
- 방문 알림 전체 사용 여부, 새 방의 기본 알림값, 입장·퇴장별 알림, 신뢰 플레이어 포함 여부, 방문자 목록 표시 상한
- 방 생성 틱당 처리량, 최대 대기 방 수, 준비 완료 후 자동 입장과 안내 여부
