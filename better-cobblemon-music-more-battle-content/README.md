# Better Cobblemon Music - More Battle Content Integration

Connects Better Cobblemon Music to Battle Tower, Battle Factory, and PvP contexts from Cobblemon: More Battle Content.

- Mod ID: `better_cobblemon_music_mbc`
- Side: client only
- Requires: Better Cobblemon Music and Cobblemon: More Battle Content

## Build

Run from the repository root:

```powershell
.\gradlew.bat :better-cobblemon-music-more-battle-content:build
```

The JAR is written to `better-cobblemon-music-more-battle-content/build/libs`.
