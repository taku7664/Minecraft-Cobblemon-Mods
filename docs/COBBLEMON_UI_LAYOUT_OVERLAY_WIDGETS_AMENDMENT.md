# Cobblemon UI 레이아웃·오버레이·선택 위젯 후속 결정

| 항목 | 값 |
| --- | --- |
| Status | `shared` |
| Effective | 2026-09-26 |
| Updates | `COBBLEMON_UI_WIDGET_PRIMITIVES_AMENDMENT.md` |
| 적용 대상 | `cobblemon-ui-kit`을 사용하는 League Challenge와 독립 GUI 모드 |

## 1. 책임 경계

UI Kit은 화면 배치, 렌더링, 포커스와 화면 안의 일시적인 선택 상태를 소유해야 한다(MUST). 도전 진행도, 서버 승인, 보상, 전투 규칙 같은 도메인 상태는 소비 모드가 소유해야 하며(MUST), UI Kit이 이를 저장하거나 판정하면 안 된다(MUST NOT).

공개 데이터 계약은 Minecraft 클라이언트 타입이나 owo 타입에 의존하면 안 된다(MUST NOT). Minecraft 위젯 적용과 실제 렌더링은 `client` 패키지에 한정해야 한다(MUST).

## 2. 레이아웃 계약

다음 순수 레이아웃을 제공해야 한다(MUST).

- `UiStackLayout`: 가로·세로 축, 패딩, 간격, 교차축 정렬과 가중치 분배
- `UiFlowLayout`: 사용 가능한 너비에 따른 줄바꿈과 행 간격
- `UiGridLayout`: 고정 열 수, 셀 간격과 정렬

레이아웃 계산은 같은 입력에 같은 논리 좌표를 반환해야 한다(MUST). 가중치 나눗셈에서 남는 픽셀도 컨테이너 안에서 모두 분배해 빈틈이나 초과가 생기지 않아야 한다(MUST).

## 3. 오버레이 계약

- 툴팁은 화면 경계를 넘지 않도록 위치를 고정하고, 대상 아래 공간이 부족하면 위로 전환해야 한다(MUST).
- 모달 대화상자는 별도 `Screen`으로 열어 배경 위젯 입력을 차단해야 한다(MUST). 취소와 확인은 명시적 콜백으로 반환해야 한다(MUST).
- 토스트는 비차단 알림 큐로 제공해야 하며(MUST), 한 항목의 표시 시간이 끝난 뒤 다음 항목을 표시해야 한다(MUST).

툴팁과 토스트가 도메인 작업을 직접 실행하면 안 된다(MUST NOT). 모달 역시 소비자가 전달한 확인·취소 의도만 호출해야 한다(MUST).

## 4. 선택·데이터 위젯

다음 위젯은 테마 표면과 한·영 번들을 공유해야 한다(MUST).

- 체크박스: 불리언 값과 변경 콜백
- 라디오 그룹: 단일 선택 보장과 비활성 항목 처리
- 콤보박스: 현재 선택, 펼침 상태와 선택 변경 콜백
- 카드: 제목, 보조문, 선택적 아이콘·의미 색상 포인트
- 통계 행: 레이블, 값과 선택적 진행 비율

콤보박스의 팝업은 현재 스크롤 뷰포트 안에서 마지막에 렌더링해 같은 뷰포트 자식보다 앞에 보여야 한다(SHOULD). 전역 포털 오버레이, 가상화 목록과 검색형 콤보박스는 이 계약에 포함하지 않는다.

## 5. 다국어와 접근성

사용자에게 보이는 문자열은 영어와 한국어 번들에서 같은 키 집합을 유지해야 한다(MUST). 아이콘이나 도형만 보이는 컨트롤도 내레이션용 레이블을 가져야 한다(MUST). 콤보박스 내레이션은 컨트롤 레이블과 현재 선택을 함께 전달해야 한다(MUST).

## 6. 현재 제외 범위

텍스트 입력, 슬라이더, 드래그앤드롭, 가상화 목록, 전역 포커스·컨트롤러 탐색 관리자는 이번 계약에 포함하지 않는다. 실제 소비 화면의 요구가 생기면 입력 소유권과 실패 처리를 포함한 별도 후속 계약으로 추가한다.

- `:cobblemon-ui-kit:check`와 `:cobblemon-ui-kit:build` 통과
