**작업 규칙.** 항목을 고치면 체크하고 커밋 해시를 적는다. 고치지 않기로 하면 이유를 적고 남긴다. 새로 찾은 빈 곳은 여기에 추가한다. Better AI 작업을 시작할 때 이 문서부터 본다.

## 2. 기술 (사용 횟수 순)

공통 원인:
- **동적 위력·타입 기술은 피해 0.** `PUBLICLY_RESOLVED_DYNAMIC_MOVES`(`LocalPublicMoveDamageInputs.kt`)에 없으면 `isUnresolvedDynamicDamage` → 루트 0점, 탐색은 우선도만. `LEGACY_UNRESOLVED_DYNAMIC_MOVES`도 같다. "기본 위력으로 대신하지 않는다"는 의도된 정책이지만, 조건부로만 위력이 바뀌는 기술까지 0이 되는 비용이 크다.
- **탐색은 대부분의 휘발 상태를 무시한다.** `applyEffect`는 STATUS와 STAT_STAGE만, `recursiveControlEffect`는 도발·앵콜·속박만 다룬다.
- **효과를 모르는 변화기는 일괄 20점** (`LocalNonDamagingMoveEvaluator` `GENERIC_STATUS_PRESSURE`).
- **콜백에서 일어나는 효과는 사라진다.** 선언 데이터(heal, boosts 등)만 읽고, `CALLBACK_EFFECTS`에는 막말내뱉기·잠자기뿐이다.

## 3. 특성·도구 (사용 횟수 순)

공통 원인:
- **상대 특성·도구는 공개된 뒤에만 쓴다(의도).** 미공개 특성은 면역·옹골참·상태이상 면역에서 "후보 전부가 막을 때"만 쓴다. 미공개 도구는 로컬에서 추론하지 않는다.
- 그래서 아래는 대부분 **우리 쪽**(특성·도구를 정확히 아는 쪽)의 빈 곳이다. 콘텐츠 세트의 대부분은 AI 트레이너 것이라, 자기 수를 잘못 평가한다.

## 5. 요청·판단 흐름 (불법 선택·전투 멈춤 위험)

정적 분석 결과다(바이트코드 포함). **실전 재현은 하지 않았다.** 고치기 전에 어댑터 단위 테스트나 개발 서버 더블 전투로 먼저 재현한다.

Cobblemon은 `|error|[Invalid choice]`를 받으면 `mustChoose=true`만 세우고 AI의 `onChoiceRequested`를 다시 부르지 않는다. 우리 액터는 `submitPreparedResponses`에서 이미 `pendingRequest`를 비웠다(394행 finally). 그래서 AI의 불법 선택은 전투 멈춤으로 이어질 가능성이 크다. 반면 `[Unavailable choice]`(숨은 트랩)는 Showdown이 요청을 다시 보낸다.

## 6. 더블 (2026-10-02 수정 후 남은 것)

- [ ] **G-501** 학습된 상대 성향 모델이 더블에서 쓰이지 않는다. 더블 응답이 모두 `COMPOSITE`라 `LocalOpponentResponseModel.responseKind`가 MOVE 하나로 묶는다.
- [ ] **G-502** 두 슬롯이 같은 상대를 칠 때 기절 확률이 부분적이면 겹쳐 센다(0.6 + 0.6 → 1.2 × 200). 확정 기절 둘만 뺀다. 범위기와 단일 대상기의 조합도 확인하지 않는다.
- [ ] **G-503** 상대 두 슬롯의 의도를 서로 독립으로 본다. 한 대상에 몰아치기 의도가 최악 응답 외에는 없다.
- [ ] **G-504** 피뢰침·마중물 흡수 시 랭크업, 아군 피뢰침이 우리 기술을 끌어가는 경우가 없다.
- [ ] **G-505** 기절 후 양쪽 교체(탐색)에서 아군을 먼저 넣고 위협·날씨를 아군 먼저 처리한다(`LocalRecursiveLookahead.kt:792-806`). 턴 시작 교체는 고쳤다.
- [ ] **G-506** 속도가 정확히 같은 두 포켓몬의 순서를 한 번 관측한 결과로 고정한다(`definiteOrder`).
- [ ] **G-507** 깊이 1 리프가 턴 뒤 국면 가치(교체해 들어온 대면, 랭크 압박)를 읽지 않는다.
- [ ] **G-508** 미지 응답 예비분 0.20을 상대 조합마다 한 번만 뺀다(한 슬롯이든 두 슬롯이든).
- [ ] **G-509** `simultaneousResponseWeight > 0`이면 두 번째 패스가 다른 후보의 응답 커버리지를 읽는다(기본 꺼짐, 잠재 버그). `LocalRecursiveLookahead.kt:280, 285-286`.
- [ ] **G-510** 네이티브 엔진의 `normal` 대상 기술이 아군 대상 후보를 만들지 않는다(꽃가루경단 회복, 집단구타+정의의마음, 스킬스왑). 레거시 경로는 꽃가루경단만 허용한다.
- [ ] **G-511** 두 슬롯 기절에 벤치가 하나뿐이면 패스가 없어 합법 행동이 없다. 기본 선택으로 넘어간다(`Cobblemon173BrainTrainerBattleActor.kt:111-117`).
- [ ] **G-512** 레거시 어댑터에서 아군 대상 공격을 막은 동작의 단위 테스트가 없다(Cobblemon 객체가 필요).
