# 엔진 작업 중 막힌 부분

작업하다 막힌 항목을 남겨 두고 다른 작업부터 진행한 기록이다. 해결하면 항목을 지운다.

## 2026-10-03 전체 완료 보고 정정과 잔여 작업

일부 치명 수정과 후속 발견 항목만 끝내고 원래 “기록하고 다 고쳐” 요청을 전체 완료한 것처럼 보고했다. 빡대리님의 “왜 다 안해놓고 했다하는겨” 지적 뒤 메인이 범위 축소와 보고 실패를 인정하고 전체 잔여 검수·수정으로 복귀했다. 전체 작업은 **미완료**이며, 아래 완료 커밋은 해당 일부 항목의 완료만 뜻한다.

[`LOCAL_GAPS.md`](LOCAL_GAPS.md)의 “2026-10-03 전체 잔여 작업 재개”에 기존 미완료 체크 35개, 이 문서의 원래 명시 OPEN 2개와 검증·구조·연결 잔여 B-001 ~ B-010, 설치기 분모 정정 H-001을 모았다. 신규 G-513/514/515까지 합친 38개 중 G-408/501/503/406/512/514/515/508/509를 소스·회귀 기준 완료했고 **미완료 체크 29개와 이 문서의 잔여는 남아 있다**. G-408은 기존 회귀를 확인한 문서 정정이다. 현재 소스 대조 → 실제 결함 회귀 실패 → 수정·통과 → 논리 단위 커밋·푸시 → 독립 검수까지 추적한다. 기존 “하지 않음” 기록을 근거로 사용자 요청에서 빼지 않는다.

## Showdown 동작

- **교체 요청에서 Showdown의 자동 선택이 오류를 낸다.** `side.chooseSwitch()`를 인자 없이 부르면 `slotText.length`에서 멈춘다. 심판 도구는 첫 번째 교체 가능한 포켓몬을 직접 지정해서 피한다. 실게임은 항상 대상을 지정하므로 영향이 없다.

## 게임 연결

- **이번 수정 버전의 실게임 행동은 미검증이다.** 2026-09-28 개발 서버의 엔진 도감 등록 1445개·네이티브 엔진 작업자 준비 230ms는 당시 부팅 증거다. 이번 소스·회귀 결과와 별개로 수정 JAR의 배포 및 실제 전투에서 판단 시간·탐색 깊이·행동을 확인하는 일이 남았다.
- **수제 계산기 동결 해제**는 아직 하지 않았다. 엔진이 게임에서 제대로 판단하는지 확인한 뒤, 수제 계산기를 엔진 호출로 바꿀지 결정한다.
