# Player Popup Emotes

V 키를 누른 채 이모트를 고르면 플레이어 머리 위에 아이콘을 띄워 주는 Fabric 모드입니다. 서버가 허용한 내장 이모트만 전송하므로 다른 플레이어가 보낸 주소에서 파일을 내려받지 않습니다.

- Mod ID: `player_popup_emotes`
- 실행 환경: 클라이언트와 서버 모두 필요
- 필요 모드: Fabric API

## 사용법

1. V 키를 누르고 있으면 이모트 메뉴가 열립니다.
2. 마우스를 원하는 아이콘 쪽으로 옮깁니다.
3. V 키를 놓으면 주변 플레이어에게 이모트가 보입니다.

키 설정은 Minecraft의 조작 설정에서 바꿀 수 있습니다. 현재 버전에는 Minecraft 기본 아이템 텍스처를 이용한 이모트 9개가 들어 있습니다. 바깥 원판은 8개 조각으로 나뉘며, 가운데에서도 인사 이모트를 고를 수 있습니다.

ESC 메뉴, 타이틀 화면의 `내 이모트` 버튼 또는 Mod Menu의 설정 버튼에서는 HTTPS 이미지 URL을 등록할 수 있습니다. PNG, JPEG, 움직이는 GIF를 지원하며, 저장한 이모트는 기본 원판 다음 페이지부터 나타납니다. 원판을 연 상태에서 좌우 방향키로 페이지를 바꿀 수 있습니다.

## 현재 범위

이 버전은 내장·URL 이모트 선택, 서버 검증, 주변 플레이어 동기화, 머리 위 표시를 지원합니다. 이미지 업로드와 효과음은 아직 지원하지 않습니다.

## 빌드

저장소 루트에서 실행합니다.

```powershell
.\gradlew.bat :player-popup-emotes:build
```

JAR은 `player-popup-emotes/build/libs`에 생성됩니다.
