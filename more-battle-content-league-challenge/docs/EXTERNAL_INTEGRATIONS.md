# 외부 모드 연동

## 1. 의존성 개요

| 대상 | 관계 | 역할 |
| --- | --- | --- |
| Cobblemon | 필수 | 포켓몬 파티와 배틀 기반 |
| More Battle Content | 필수 | 관리형 PvE 전투, BP, 시설 잠금 정책 |
| PokeBadges | 필수 | 획득 뱃지의 외부 표시와 호환 |
| 레벨캡 제공자 | 미확정 | 플레이어별 포켓몬 레벨 제한 |
| MBC Better AI | 선택 | 관장·사천왕·챔피언의 확장 AI |
| MBC Better Music | 선택 | 도전 종류별 음악 |

정확한 모드 ID와 지원 버전 범위는 실제 대상 JAR로 확인한 뒤 `fabric.mod.json`에 고정한다.

## 2. PokeBadges

PokeBadges는 필수 의존성으로 사용한다. League Challenge가 진행도의 권위 원본이고, PokeBadges는 플레이어가 가진 뱃지를 외부에 표시하는 동기화 대상이다.

채택 규칙:

- 관장 승리 확정 후 League Challenge 진행도를 먼저 기록한다.
- 대응 뱃지는 PokeBadges의 공개 API로 지급한다.
- PokeBadges에 뱃지가 있다는 이유만으로 League Challenge 승리를 자동 인정하지 않는다.
- 외부 지급 실패는 조정 대기 상태로 기록하고 로그인·리로드 때 재시도한다.
- 뱃지를 수동 제거해도 내부 승리 기록은 자동 삭제하지 않는다.
- 기존 서버 이관이 필요하면 명시적 관리자 가져오기 명령을 별도로 제공한다.

현재 검토한 공개 API에는 뱃지 지급·보유 확인·제거·복원·목록·지역 완료와 관련 이벤트가 있다. 실제 구현에서는 대상 버전의 메서드와 식별자 형식을 다시 컴파일 검증한다.

PokeBadges의 배포 라이선스와 API 사용 조건을 준수한다. 해당 모드의 코드나 자산을 League Challenge에 복사하지 않고 얇은 어댑터로 격리한다.

## 3. 레벨캡 제공자

Cobblemon의 전역 최대 레벨 설정은 서버 전체 값이라 뱃지별 개인 진행도에는 충분하지 않다. 검토한 Mega Showdown JAR에서도 이 요구를 충족하는 공개 개인 레벨캡 시스템을 확인하지 못했다.

현재 1순위 후보는 **Cobbled Level Control**이다. 다만 Cobblemon 1.8.1 환경의 실제 API와 서버 동작을 아직 검증하지 않았으므로 채택 확정으로 쓰지 않는다.

어댑터는 다음 좁은 계약을 가져야 한다.

- 플레이어의 현재 유효 캡 조회
- 뱃지 진행도에서 계산한 캡 반영
- 로그인·진행 변경·리로드 때 동기화
- 제공자 부재 또는 오류를 감지하고 도전을 안전하게 차단

후보가 맞지 않으면 `Cobblemon Level Cap`, `CobbleRegions`, 또는 League Challenge 자체 구현을 비교한다. 공급자 전용 타입은 코어 진행 로직 밖의 어댑터에만 둔다.

## 4. MBC

League Challenge는 MBC의 내부 패키지를 직접 사용하지 않는다. MBC가 제공할 공개 계약만 사용한다.

- 관리형 PvE 배틀 시작 및 결과 수신
- 트레이너 가상 투영과 리소스 스킨 표현
- BP 원자적 지급
- Battle Tower·Battle Factory 접근 정책 등록
- 클라이언트 전용 `MbcUI` 화면 문서·토큰·컴포넌트 사용

League Challenge는 owo·`GuiGraphics`와 MBC 내부 레이아웃 타입을 직접 사용하지 않는다(MUST NOT). Minecraft UI 백엔드는 MBC가 소유하며 League는 공개 화면·상태·행동 계약에만 의존한다(MUST).

MBC는 League Challenge를 의존하거나 클래스 이름으로 탐색하지 않는다. 애드온이 초기화될 때 정책과 공급자를 등록하고 서버 종료 때 해제한다.

## 5. 선택 애드온

### Better AI

설치되어 있으면 데이터가 지정한 난이도 또는 브레인 ID를 공개 AI 계약으로 전달한다. 없으면 MBC 기본 AI로 정상 동작한다. 기본 데이터팩이 선택 애드온 전용 ID만 요구해서는 안 된다.

### Better Music

설치되어 있으면 `gym`, `elite_four`, `champion`과 같은 안정적인 콘텐츠 ID로 음악을 선택할 수 있게 한다. 없으면 무음 또는 기본 배틀 음악으로 진행하며 전투 결과에는 영향이 없다.

## 6. MBC BP

새 화폐를 만들지 않는다. 반복 도전이나 리그 보상에 포인트가 필요하면 MBC BP를 사용한다. 금액과 최초·반복 보상 차이는 데이터팩으로 정의하되, 지급은 거래 ID와 이유를 가진 MBC 공개 원자적 API로 처리한다.

## 7. 장애 원칙

| 장애 | 처리 |
| --- | --- |
| 필수 PokeBadges 없음 | 로딩 단계에서 명확히 실패 |
| 레벨캡 제공자 없음/비호환 | 서버 시작 또는 도전 진입을 명확한 오류로 차단; 조용히 무제한 허용하지 않음 |
| 선택 Better AI 없음 | MBC 기본 AI 사용 |
| 선택 Better Music 없음 | 기본 음악 사용 |
| 뱃지 외부 반영 실패 | 내부 승리는 유지하고 조정 큐에서 재시도 |
| MBC 접근 정책 오류 | Tower·Factory 새 진입은 잠그고 다른 MBC 콘텐츠는 유지 |
| 스킨/초상화 누락 | 기본 외형으로 대체하고 전투는 계속 |

호환성 문제를 숨기기 위한 무제한 리플렉션은 사용하지 않는다. 지원 버전을 명시하고 컴파일·통합 테스트로 API 변화를 발견한다.
