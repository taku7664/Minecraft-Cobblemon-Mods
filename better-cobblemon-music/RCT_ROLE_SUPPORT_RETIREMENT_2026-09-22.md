# Better Cobblemon Music RCT 역할별 선곡 지원 종료

| 항목 | 값 |
|---|---|
| Status | `shared` |
| Effective | 2026-09-22 |
| Obsoletes | `RELIABILITY_UPDATE_2026-08-22.md` §3의 RCT 역할 캐시 2개 조항, §7의 역할 키 제한 테스트 요구 |
| 대상 | RCT 연동, 트레이너 역할별 선곡, `battle.roles`, 구형 `battle.gym` |
| 주 독자 | 빡대리님과 이후 구현·검증 담당자 |

## 1. 런타임 계약

- 상대 진영에 NPC actor가 있으면 트레이너 전투로 분류해야 **MUST** 한다.
- NPC의 RCT 타입이나 역할을 조회해서는 안 된다 **MUST NOT**.
- 모든 NPC 트레이너 전투는 포켓몬별 규칙과 콘텐츠 ID가 선택되지 않은 경우 `battle.trainer`를 사용해야 **MUST** 한다.
- RCT 설치 여부와 무관하게 월드 엔티티를 역할 판별 목적으로 순회해서는 안 된다 **MUST NOT**.

## 2. 설정 계약

- `battle.roles`와 구형 `battle.gym`은 지원되는 설정 키가 아니어야 **MUST** 한다.
- 두 키가 들어 있는 설정은 정확한 JSON 경로를 포함한 알 수 없는 항목 오류로 거부해야 **MUST** 한다.
- 번들 기본 설정에는 역할별 플레이리스트가 없어야 **MUST** 한다.
- 사용자 설정 파일을 자동 수정해서는 안 된다 **MUST NOT**. 사용자가 기존 두 키를 직접 제거한 뒤 `/bcm reload`를 실행해야 **MUST** 한다.

## 3. 제거 범위

- RCT 반사 호출, actor UUID 캐시, RCT 타입 변환기, 역할 우선순위, 역할별 생성팩 음원 수집은 제거해야 **MUST** 한다.
- 관련 단위 테스트와 현재 사용법 문서는 새 계약에 맞춰 정리해야 **MUST** 한다.
- 과거 공유 결정문은 결정 이력을 보존하기 위해 삭제하거나 소급 수정하지 않아야 **MUST** 한다.

## 4. 검토했지만 채택하지 않은 대안

- `battle.roles`를 계속 읽되 무시하는 방식은 설정 오타와 폐기된 기능을 숨기므로 채택하지 않는다.
- RCT 조회 코드만 남기고 결과를 사용하지 않는 방식은 불필요한 엔티티 순회와 반사 호출을 유지하므로 채택하지 않는다.
- 기존 사용자 설정을 자동 변환하는 방식은 사용자 파일을 예고 없이 수정하므로 채택하지 않는다.
