Better Cobblemon Music 개인 음악팩
==================================

공식 음악팩은 그대로 두고, 내 노래를 추가해서 원하는 상황에 연결하는 리소스팩입니다.
Better Cobblemon Music 1.3.0 이상과 공식 음악팩이 필요합니다.


1. 노래 넣기
------------
assets\mymusic\sounds\music 폴더에 .ogg 파일을 넣습니다.

- .ogg(Ogg Vorbis)만 쓸 수 있습니다. mp3, wav는 Audacity 같은 프로그램으로 ogg로 변환하세요.
  ffmpeg가 있다면:  ffmpeg -i 원본.mp3 -c:a libvorbis -q:a 5 새이름.ogg
- 파일·폴더 이름은 영어 소문자, 숫자, _ - . 만 쓸 수 있습니다. (한글, 대문자, 띄어쓰기 불가)
  예) hub_theme.ogg, champion-remix.ogg
- 폴더로 묶으면 그 폴더가 하나의 플레이리스트가 됩니다.
  예) music\hub\a.ogg, music\hub\b.ogg  →  mymusic:folder/hub (두 곡을 번갈아 재생)


2. 팩 갱신하기
--------------
update-music.bat을 더블클릭합니다.
노래 목록을 읽어 sounds.json과 음악 카탈로그를 새로 만들고, 쓸 수 있는 플레이리스트를 보여 줍니다.
노래를 추가·삭제·이름 변경할 때마다 다시 실행하세요.

곡명 입력 (Better Cobblemon Music 1.3.7의 곡명 알림)
-------------------------------------------------
팩 최상위의 track-titles.json에 표시할 이름을 적습니다. 파일명은 영문 소문자로 유지하고,
표시 이름은 한글·띄어쓰기·기호를 사용할 수 있습니다. 예:

{
  "mymusic:hub_theme": "내 광장 음악",
  "mymusic:hub/a": "Eterna Forest"
}

키는 파일 확장자 .ogg를 제외한 트랙 ID입니다. 입력하지 않은 곡은 파일명을 사용합니다.
입력 후 update-music.bat을 실행하세요. 다시 실행해도 track-titles.json의 이름은 보존됩니다.
생성 카탈로그의 tracks 안에 있는 title에 기록되고, 게임에서 F3+T 후 새 곡부터 적용됩니다.
Mod Menu → Better Cobblemon Music → 재생 → BGM 곡명 알림 표시에서 ON/OFF를 바꿉니다.

만들어지는 플레이리스트:
- mymusic:all                  넣은 노래 전부
- mymusic:folder/<폴더>         그 폴더의 노래
- mymusic:track/<파일 이름>      노래 한 곡


3. 게임에 적용하기
------------------
1) 이 폴더(my-music-pack)를 마인크래프트의 resourcepacks 폴더에 넣고, 리소스팩 화면에서 켭니다.
   공식 음악팩(cobleserver-music-resourcepack)도 켜져 있어야 합니다. 순서는 상관없습니다.
2) 이미 켜 둔 상태에서 노래를 바꿨다면 게임 안에서 F3+T로 리소스를 다시 불러옵니다.
3) 모드 메뉴 → Better Cobblemon Music 설정에서 상황별로 플레이리스트를 고르고 저장합니다.
   - 필드 음악 매핑: 기본 필드곡, 차원, 바이옴
   - 전투 음악 매핑: 야생·트레이너·PvP, 콘텐츠(리그 체육관·사천왕·챔피언, 배틀타워 보스 등)
   - 화면 음악 매핑: 배틀 허브(more_cobblemon_contents:hub, 탭별로 hub/shop 등)


설정 화면에 없는 키에 연결하고 싶을 때
-----------------------------------
config\better_cobblemon_music\overrides.json을 직접 고칩니다. 예를 들어 시로나와의 챔피언전에만 다른 곡을 쓰려면:

{
  "schemaVersion": 1,
  "battle": {
    "content": {
      "more_cobblemon_contents:league_challenge/champion/cynthia": "mymusic:track/champion_remix"
    }
  },
  "screens": {
    "more_cobblemon_contents:hub": "mymusic:folder/hub"
  }
}

저장한 뒤 게임에서 /bcm reload 를 입력하면 바로 적용됩니다.


문제가 생기면
------------
- 노래가 안 나오면 update-music.bat 결과에 "건너뛴 파일"이 있는지 확인하세요.
- 로그(logs\latest.log)에서 "Rejected catalog" 또는 "unavailable" 문구를 찾으면 원인이 적혀 있습니다.
- namespace(mymusic)는 바꾸지 않는 것을 권합니다. 바꾸려면 assets\mymusic 폴더 이름과
  update-music.ps1 맨 위의 $ns 값을 함께 바꾸세요.
