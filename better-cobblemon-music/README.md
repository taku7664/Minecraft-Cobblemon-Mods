# Better Cobblemon Music

Data-driven field, battle, and hit audio presentation for Cobblemon.

- Mod ID: `better_cobblemon_music`
- Side: client only
- Requires: Fabric API and Cobblemon 1.7.3

## Build

Run from the repository root:

```powershell
.\gradlew.bat :better-cobblemon-music:build
```

The JAR is written to `better-cobblemon-music/build/libs`.
