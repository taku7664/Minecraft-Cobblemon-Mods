# 텍스트 BGM 곡명 알림

2026-10-03. 대상: 빡대리와 음악 모드 유지보수자.

BGM의 실제 재생 시작 이벤트에 연결합니다. 처음 시작한 곡과 다른 곡으로 바뀔 때 좌측 상단에 곡명만 표시합니다. 패널·배경·버튼·알림음은 없습니다. 약 0.35초 동안 슬라이드·페이드 인, 2.2초 유지, 0.45초 슬라이드·페이드 아웃입니다. 긴 이름은 화면 너비 안으로 자릅니다.

Mod Menu → Better Cobblemon Music → 재생 → **BGM 곡명 알림 표시**에서 ON/OFF를 바꿉니다. `settings.json`의 `nowPlayingEnabled`이며 기본은 `true`입니다. 속성이 없는 기존 설정도 ON으로 읽고 원본 파일을 강제로 재작성하지 않습니다. 다른 설정을 저장해도 OFF 값이 유지됩니다. OFF로 저장하면 현재 알림을 지우며, 다시 ON으로 바꿔도 지난 알림을 재생하지 않습니다.

같은 음원의 반복·상황 재검사·HP 효과 변화는 알림을 재시작하지 않습니다. 다른 플레이리스트 곡으로 넘어가면 새 알림으로 교체하며 대기열을 쌓지 않습니다. BGM 타격음과 저체력 경고음은 재생 시작 이벤트가 별개라 알림 대상이 아닙니다. 곡이 없어진 전환에서는 알림 상태를 지웁니다.

월드 HUD와 메뉴 화면에 각각 연결하되 화면이 열렸을 때 HUD 쪽은 그리지 않아 중복 표시를 피합니다. F1의 HUD 숨김을 따릅니다. 애니메이션은 화면 시계로 계산하므로 상황 검사 1초 주기와 별개로 부드럽게 그리지만, 새로운 상황 검사는 기존 공용 주기를 그대로 사용합니다. 실제 곡 선택이 아닌 재생 시작에만 반응합니다.

이름은 [리소스팩 곡명 입력](TRACK_TITLES_2026-10-03.md)의 카탈로그 `title`을 사용합니다. 외부 팩 이름의 줄바꿈·제어문자·Minecraft 색상 명령은 제거하며 문자열 길이를 제한합니다.

검증: 알림 시작/유지/퇴장/만료, 같은 곡 반복 억제, 새 곡 교체, OFF/ON, 문자열 정리, 자연스러운 다음 곡 시작 이벤트, 설정 저장·로드·컴파일과 한글/영문 번역을 단위 테스트했습니다. UI 렌더링은 단위 TDD로 직접 검증할 수 없어 컴파일과 연결 코드를 확인했으며, 실제 게임의 좌표·글꼴·화면 중복은 별도 시각 검증이 필요합니다.
