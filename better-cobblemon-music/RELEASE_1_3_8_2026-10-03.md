# Music 1.3.8 한국어 곡명 배포

2026-10-03. 대상: 빡대리와 유지보수자. 클라이언트는 `C:\Users\박주형\AppData\Roaming\ModrinthApp\profiles\cobblemon-dev`입니다. 서버에는 변경하지 않았습니다.

## 포함 변경

- [한국어 곡명 대조](KOREAN_TRACK_TITLES_2026-10-03.md): 공식 BGM 112개 표시명을 한국어로 변경.
- 게임명은 요청한 영문 약자 형식으로 표시: `전투! 루기아 (HG·SS)`, `전투! 디아루가·펄기아 (D·P)` / `(BD·SP)`. 필드 원곡의 `(낮)` / `(밤)`은 유지.
- 나무위키 원문을 직접 열지 못해 작품별 OST 미러와 다국어 지명표, 입력 파일명·앨범 태그를 대조. 공식 제목을 확정하지 못한 설명명은 위 문서에 별도로 명시.
- 음원·음량·선곡·매핑·알림 애니메이션·설정 화면 동작은 변경하지 않음.

## 소스·빌드 검증

약자 형식의 회귀 테스트를 먼저 실행해 긴 게임명 때문에 2개가 실패하는 것을 확인한 뒤 표시명을 변경했습니다. 이후 `:better-cobblemon-music:unitTest --no-daemon`와 `:better-cobblemon-music:build --no-daemon` 모두 성공, 테스트 155/155 통과.

이전 소스와 비교해 `catalog-layout.json`의 `trackTitles` 112개 값만 바뀌고 트랙 ID와 나머지 레이아웃은 동일함을 확인했습니다. 실제 팩 생성 → 카탈로그 파싱 → 재생 이벤트 제목 컴파일을 통해 한국어·주요 고유명·영문 약자의 전달을 검사합니다. 테스트는 번역이 공식 명칭인지 판정하는 도구가 아닙니다.

ZIP 전체 CRC 검사 통과. 설치된 1.3.7과 파일 목록이 같고, 기존 116개 OGG(112 BGM + 4 효과음)가 SHA-256 기준 모두 동일합니다. 바뀐 파일은 기본 카탈로그 `assets/better_cobblemon_music/catalogs/base/cobleserver.json` 하나이며, 그 안에서도 `tracks[*].title`만 변경됐습니다. 플레이리스트·매핑·트랙의 다른 속성은 동일합니다.

JAR CRC, 1.3.8 버전, 클라이언트 환경, Mod Menu entrypoint, `NowPlayingTextOverlay` 포함을 확인했습니다. 이전 JAR과 비교하면 `fabric.mod.json`의 버전 값만 다르고 재생·설정 클래스는 모두 동일합니다. 추가 검사에서 처음에는 실제 이름과 다른 `NowPlayingOverlay`를 검사해 실패했고, 소스·JAR에서 실제 클래스명을 확인한 뒤 검사명을 정정해 통과했습니다. 제품 코드 수정으로 숨긴 실패가 아닙니다.

## 배포 검증

Minecraft 클라이언트 프로세스가 실행 중이 아님을 확인한 뒤 배포했습니다.

- `mods/better-cobblemon-music-1.3.8.jar`만 활성 Music JAR로 설치.
- `resourcepacks/cobleserver-music-resourcepack-1.3.8.zip` 설치. `options.txt`의 선택된 음악팩 파일명만 1.3.7 → 1.3.8로 변경했으며 다른 옵션은 동일함을 확인.
- 개인 `settings.json`, `overrides.json`은 배포 전 백업과 SHA-256이 같음. 음량·매핑 등 개인 설정은 재작성하지 않음.
- 이전 JAR·옵션·개인 설정 백업: `deployment-backups/music-korean-titles-1.3.8-20261003`.
- 이전 1.3.7 ZIP은 클라이언트 리소스팩 폴더에 비활성 상태로 보존. 롤백 시 이전 JAR을 복구하고 음악팩 선택을 1.3.7로 되돌림.
