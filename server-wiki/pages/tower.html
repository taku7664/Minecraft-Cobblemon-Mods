배틀타워

연승에 도전하는 시설입니다. 이길수록 받는 BP가 늘고, 5연승마다 보스가 나옵니다. 리그 챔피언이 되어야 이용할 수 있습니다.

참가 방법

  • 광장에 있는 배틀타워 터미널을 우클릭해 허브를 엽니다.
  • 파티에 정확히 6마리를 데리고 가서 등록합니다. 같은 종을 두 마리 넣거나 같은 도구를 두 개 들게 할 수 없습니다.
  • 싱글 배틀은 6마리 중 3마리를, 더블 배틀은 4마리를 골라 싸웁니다. 배틀 사이에 "팀 변경"으로 다시 고를 수 있습니다.
  • Lv.50보다 높은 포켓몬은 Lv.50으로 맞춰서 싸웁니다. 낮은 포켓몬은 그대로입니다.
  • 가방 아이템은 쓸 수 없습니다.

도전 설정

  • 메가진화, 다이맥스, 테라스탈 중 하나를 고릅니다. 양쪽 모두 한 배틀에 한 번 쓸 수 있습니다.
  • 전설급(전설, 환상, 울트라비스트, 패러독스)을 허용할지 고릅니다. 비허용이면 양쪽 모두 쓸 수 없고, 선출 화면에서 전설급 포켓몬 카드가 붉게 표시되어 고를 수 없습니다.
  • 허용이면 한 배틀에 전설·준전설 1마리와 환상·울트라비스트·패러독스 1마리까지, 최대 2마리를 데려갈 수 있습니다. 상대도 내가 데려온 만큼 전설급을 데려옵니다(전설을 데려가면 상대도 전설, 환상 등을 데려가면 상대도 그쪽).
  • 두 설정은 첫 배틀을 시작하면 도전이 끝날 때까지 바꿀 수 없습니다.

연승과 BP

단계연승승리당 BP
입문1~51
실전6~102
고급11~203
프로21 이상4
  • 5번째 승리마다 보스 배틀이고, 이기면 +5 BP를 더 받습니다. 예를 들어 5연승째는 6 BP, 10연승째는 7 BP입니다. 25연승까지 모두 합하면 90 BP입니다.
  • 지면 지금 연승이 0이 됩니다. 최고 연승 기록은 남습니다.
  • 배틀 도중에 포기하거나 접속이 끊기면 진 것으로 처리됩니다.
  • 싱글과 더블의 연승은 따로 셉니다.

상대

  • 상대 레벨은 Lv.50에서 시작해 5승마다 1씩 오릅니다(1~5연승째 Lv.50, 6~10연승째 Lv.51, 11연승째부터 Lv.52, 49연승째 Lv.59, 최대 Lv.100). 내 포켓몬은 계속 Lv.50입니다.
  • 일반 트레이너의 육성은 단계에 따라 올라갑니다. 입문(1~5연승째)은 개체값 15에 노력치 없음, 실전(6~10연승째)은 개체값 20에 노력치 252, 고급(11~20연승째)은 개체값 25에 노력치 384, 프로(21연승째부터)는 개체값 31에 노력치를 모두 채운 팀입니다. AI도 입문, 일반, 상급 순으로 강해지고 프로도 상급으로 싸웁니다. 고급 단계부터는 강한 트레이너 "타워 에이스"도 일반 상대로 섞여 나옵니다.
  • 5연승마다 챔피언이 보스로 나옵니다. 챔피언은 그린·목호·성호·윤진·난천·노간주·아이리스·카르네·테사·네모와 챔피언급 트레이너 N까지 11명입니다. 11명이 무작위 순서로 한 번씩 돌아가며 나오므로, 한 바퀴를 다 돌기 전에는 같은 챔피언을 다시 만나지 않고 같은 챔피언이 두 번 연속 나오지도 않습니다. 보스 AI는 가장 강한 보스 단계입니다.
  • 그린·목호·난천은 RCT Trainers+ 리소스팩, 나머지 8명은 More Radical Textures 리소스팩(More Radical Trainers 애드온)의 스킨을 입습니다. 리소스팩이 없으면 기본 스킨으로 보입니다.
  • 챔피언은 단계와 상관없이 원작 엔트리를 최대 실전으로 키운 팀(개체값 31, 노력치 최대, 배틀용 도구)을 쓰고, 에이스는 꼭 데려옵니다(그린 거북왕, 목호 망나뇽, 성호 메타그로스, 윤진 밀로틱, 난천 한카리아스, 노간주 불카모스, 아이리스 액스라이즈, 카르네 가디안, 테사 키라플로르, 네모 빠르모트, N 조로아크). 같은 챔피언이라도 포켓몬마다 기술 배치가 여러 벌이라 만날 때마다 팀이 달라집니다.
  • 메가진화 도전에서는 챔피언 팀의 한 마리가 메가진화합니다. 난천이라면 메가한카리아스Z, 메가한카리아스, 메가루카리오(물리·특수) 중 하나입니다. 원작 엔트리에 메가진화가 없는 노간주와 네모는 메가진화 도전에서만 염무왕과 드닐레이브가 메가스톤을 들고 합류하고, N은 원작에서도 데려온 곤율거니가 메가진화합니다. 싱글에서 에이스와 전설이 세 자리를 모두 채우고 에이스가 메가진화하지 못하면 메가진화 없이 싸웁니다. 다이맥스 도전에서는 거북왕·리자몽·라프라스가 거다이맥스할 수 있습니다.
  • 전설급을 허용한 도전에서는 챔피언도 내가 데려온 수만큼 전설을 데려옵니다. 메인 전설이 먼저 나오고, 나머지는 서브 전설 중 무작위입니다. 전설은 정해진 멤버의 자리를 대신합니다.
    • 그린: 후딘 → 뮤츠, 피죤투 → 썬더, 나시 → 파이어, 거대코뿌리 → 뮤
    • 목호: 보만다 → 레쿠쟈, 킹드라 → 라티오스, 리자몽 → 라티아스, 프테라 → 고동치는달
    • 성호: 보스로라 → 그란돈, 점토도리 → 지라치, 릴리요 → 테오키스, 아말도 → 무쇠가시
    • 윤진: 고래왕 → 가이오가, 메깅 → 마나피, 로파파 → 굽이치는물결, 독파리 → 볼케니온
    • 난천: 화강돌 → 기라티나, 토게키스 → 크레세리아, 루카리오 → 히드런, 로즈레이드 → 아그놈
    • 노간주: 바닐리치 → 큐레무, 어지리더 → 땅을기는날개, 버프론 → 케르디오, 슈바르고 → 비크티니
    • 아이리스: 크리만 → 제크로무, 라프라스 → 날뛰는우레, 아케오스 → 무쇠머리, 삼삼드래 → 아고용
    • 카르네: 아마루르가 → 제르네아스, 견고라스 → 디안시, 펌킨인 → 후파, 루차불 → 무쇠무인
    • 테사: 고고트 → 코라이돈, 클레스퍼트라 → 무쇠감투, 크레베이스 → 무쇠암석, 꿰뚫치 → 복숭악동
    • 네모: 꿈트렁 → 미라이돈, 루가루암 → 무쇠손, 미끄래곤 → 제라오라, 노고고치 → 무쇠바퀴
    • N: 바닐리치 → 레시라무, 기기기어르 → 게노세크트, 늑골라 → 메로엣타, 아케오스 → 무쇠독나방
