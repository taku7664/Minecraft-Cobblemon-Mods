## 확인한 것과 확인하지 못한 것

## 재현해 수정한 문제

기존 계산은 `canonicalKnownHeldItemId == null`이면 기본 위력의 두 배를 적용했다. 그러나 공개 상태에서 null은 **상대 도구를 아직 모름**도 포함한다. 도구 없음이 확인되지 않은 상대를 무도구로 확정해 위력110으로 예측하는 별도 오류가 재현됐다.

기본 위력은 기술 데이터에서 읽는다. 변경된 배율 조건은 다음과 같다.

| 입력 | 기존 | 수정 후 |
|---|---:|---:|
| 자신의 도구 없음: 정확한 자기 상태 | 2배 | 2배 |
| 상대 도구 없음: 관측기가 빈 문자열로 확인 | 2배 | 2배 |
| 자뭉열매 등 도구 보유 확인 | 1배 | 1배 |
| 상대 도구 미확인: null | 2배 | 1배 |

상대 도구 미확인 시에는 무도구 보너스를 확정하지 않고 기본 위력을 사용한다. Poltergeist의 공개 도구 존재 판정과 같은 지식 경계를 따르며, Knock Off도 보너스가 확인되지 않으면 기본 위력을 쓰는 기존 원칙과 맞는다. 도구 효과가 정지된 경우에도 보유 자체는 사라지지 않는다.

자기 포켓몬의 도구가 null인 옛 입력은 정확한 무도구라는 기존 의미를 유지한다. 새 점수 상수·고정 감점·순위 뒤 보정·추첨 제외는 추가하지 않았다. 이 수정은 **당시 루차불의 자기 도구 입력 오류를 재현해 고쳤다는 뜻이 아니다.**
