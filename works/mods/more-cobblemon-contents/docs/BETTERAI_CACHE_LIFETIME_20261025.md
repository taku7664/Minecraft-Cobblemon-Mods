## 요청과 범위

사용자가 재사용이 끝난 임시 판의 참조를 바로 끊으라고 지시했다. 기준2caaf3ec1,1b39/codex/betterai-entry-healblock이다. 분기가 왜 남아 있는지에 대한 질문은 원인 확인과 분리했다. 이번 변경은 계산식·피해 난수·확률 분기·현재 행동 랭크 점수·최적화 옵션을 바꾸지 않는다. 앞서 피격 계산식도 바꾸겠다는 진행 보고는 질문 범위를 넓혔기에 정정했다. 분기 제거가 완료됐다고 보고하지 않는다.

LocalDecisionCalculationScope는 tables/values/종료 콜백을 finally에서 비우고 바깥 계산을 복원한다. 중첩 계산의 완료로 바깥 테이블을 비우지 않는다. LocalProjectedActionCalculationCache.close는 모든 소유 맵과 LocalBattleStateFingerprint의 판/포켓몬/이력 참조를 비운다. 닫힌 캐시에 다시 요청하면 같은 값을 새로 계산한다. 계산 횟수 계측 값은 남는다.

공통 단일 슬롯은 순수 상태 함수의 재사용이므로 스레드 경합 시 재계산이 허용된다. 종료 시 이미 다른 슬롯으로 바뀌어 있으면 그대로 둔다. 계산 범위 밖에서 만들어진 단일 슬롯의 기존 한 개 상한은 유지한다. 모든 가능한 외부 호출·게임 객체의 전체 참조 그래프를 검증했다는 뜻은 아니다. 값만 가진 KO 누적표 등의 전역 캐시는 이번 대상이 아니다.
