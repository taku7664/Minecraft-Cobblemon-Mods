## 계산 전후

기존 미래 대면은 변경된 판마다 양쪽 기술 후보를 읽고, 정밀 전술 피해·피해 롤·최대 1,000칸의 KO 누적표를 만든 뒤 기술 조합의 교환을 평가했다.

새 경로는 초기 판·사용자·상대·카탈로그·튜닝별로 기준 피해 롤을 한 번 준비한다. 미공개 상대 특성은 가능한 특성별로 따로 준비하고, 최종 교환 결과를 평균한다. 서로 다른 특성의 피해를 먼저 평균해서 확정 KO로 바꾸지 않는다. 초기 준비도 전체 대면·KO 계산을 부르지 않고 기술 후보와 기준 피해 롤만 만든다.

미래의 각 일반 피해 롤은 다음 근사다.

```
F = 실제 위력 × 유효 공격 능력치 / 유효 방어 능력치 × 피해 보정 / 상대 최대 HP
미래 피해 롤 = 기준 피해 롤 × F(미래 판) / F(기준 판)
```

공격·방어 랭크, 천진·급소, 특성·도구·날씨·필드·자속·타입·광역 배율은 공통 계산기의 입력과 보정 함수를 읽는다. 바디프레스·속임수 등 공격 능력치의 주인도 공통 입력으로 정한다. 직접 HP/레벨 피해는 기존의 가벼운 선언 계산을 읽는다. 배율 입력을 해석할 수 없거나 기준 배율이 0이면 기준 피해를 유지하고 내부 기록에 해석 여부를 남긴다.

장기 교환은 첫 타격 KO 확률과 명중은 피해 롤에서 읽고, 이후는 평균 피해와 필요 타격 수를 쓴다. 일반적인 일정 피해에서는 다음과 같다.

```
q = 명중했을 때 첫 타격 KO 확률
h = 첫 타격을 버틴 뒤 필요한 평균 피해 타격 수 + 1
예상 사용 수 = [1 + (1-q) × (h-1)] / 명중 확률
```

연속 사용 시 확정 공격 랭크 변화는 공통 랭크 적용기로 평균 피해 열을 만든다. 선공은 실제 우선도·속도 순서에서 읽는다. 기합의띠·옹골참·탈, 게으름·재사용 간격, 수면·마비와 잔여 피해도 간단 교환에 반영한다. 광역기의 기준 피해는 대상별로 준비하며 다이맥스 기술은 기본 기술 ID로 점수에 연결한다. 회복기를 읽을지는 기존 `matchupRecovery`를 따른다.

**근사의 한계:** 정밀 피해 공식의 덧셈·내림과 미래의 피해 분포 누적을 그대로 재현하지 않는다. 후속 타격의 피해·행동 불가·잔여 피해·회복에 대한 전체 턴 분기를 재생하지 않는다. 기본 기술마다 특수 스크립트의 모든 연속 사용 효과를 정밀하게 유지하는 옵션이 아니다. 실제 승률이나 플레이 안전성은 이번 검사로 확인하지 않았다.
