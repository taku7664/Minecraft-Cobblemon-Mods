# 상태기 후속 대면·행동 확률 계산식 대체

기준 소스 `2c9d6f995`, 워크트리 `1b39`, 브랜치 `codex/betterai-entry-healblock`. 기존 1번 `skipUnusedStatusMatchups`와 2번 `firstHitActingChance`는 주변 호출을 줄이는 기술 최적화였으며, 계산식을 상수나 간단식으로 대체하라는 사용자 요청을 충족하지 못했다. 이번에는 별도 기본 OFF 키 `simpleStatusMatchups`·`simpleActingChance`로 정밀 경로 본문을 대체한다. 기존 키를 켜 둔 설정에 근사를 몰래 활성화하지 않으며 Mod Menu의 마지막 두 스위치는 새 근사를 제어한다.

## 1번: 상태기 후속 대면

기존: 피격 후·효과 적용 후·더블 파트너의 판마다 `pairMatchup` → 양쪽 기술 후보/전술 피해/피해 롤 → 최대 6회 KO 누적 자료 → 양쪽 최대 4개 기술의 교환 평가·재선택을 수행한다. 기존 캐시에 있으면 실제 본문은 실행되지 않을 수 있으므로 호출 진입과 실제 피해 계산을 별도로 센다.

대체: 기존 대면의 양쪽 대표 공격을 고정한다. 원래 판의 피해 구간은 그 자체를 상수 입력으로 쓰고, 바뀐 판에서는 아래 식만 적용한다.

```
F = 위력 × 유효 공격 / 유효 방어 × 피해 보정 / 대상 최대 HP
r = F_after / F_before
D_min,max = clamp(기존 피해 구간 × r, 0, 남은 HP)
평균 턴 피해 d = 명중률 × (D_min + D_max) / 2
필요 타격 수 T = ceil(대상 HP / d), d=0이면 무한대
w = 우리 T가 작으면 1, 크면 0, 같으면 실제 선공 확률
h_win = clamp(우리 HP − 상대 평균 피해 × max(0, 우리 T − 선공 확률))
h_loss = clamp(상대 HP − 우리 평균 피해 × max(0, 상대 T − 상대 선공 확률))
E = w × (0.5 + 0.5 × h_win) − (1−w) × (0.5 + 0.5 × h_loss)
```

`F`는 기존 역학의 위력·실제 능력치·천진/능력치 무시·타입·보정 배율을 읽는 `damageFactor`다. 피해 롤을 생성하는 함수가 아니다. 해석할 수 없는 스크립트 기술 등은 기존 피해 구간을 고정하며 정밀 대면으로 돌아가지 않는다. 첫 타격의 알려진 기합의띠·옹골참·탈은 공통 역학으로 제한한다. 새로운 보너스 200점 같은 상수는 추가하지 않았다. 0.5/0.5 HP 가중은 기존 교환 점수 정의에서 가져온다.

상태기의 최종 결합식은 유지한다. `s`는 기존 첫 피격 생존 확률, `a`는 기술 명중률이다.

```
expected = s × [a × E_landed + (1−a) × E_missed] − (1−s) + a × partnerGain
statusValue = clamp(expected − E_before, −1, 1)
```

사용 전 `E_before`도 같은 간단식으로 계산한다. 정밀 사용 전 값과 근사 사용 후 값을 섞어 생기는 가짜 이득을 막기 위한 것이다. 효과 적용 대상·면역·랭크 변화 적용은 기존 공통 함수를 유지한다. `LocalStatStageMarginalEvaluator`·현재 행동의 랭크 점수식은 수정하지 않는다.

잃는 정보: 효과 적용 후 더 좋은 기술로 바꾸는 선택, 장기 회복·잔여 피해·연속 사용의 자기 랭크 변화, 전체 KO 분포. HP 상한에 잘린 기존 피해에서 원래 초과 피해를 복원할 수 없어 큰 배율 변화도 거칠게 읽는다. 이는 값 보존 최적화가 아니다.

## 2번: 행동 가능 확률

기존: 상대별 `moveMatchups`와 가능 다이맥스 공격 자료를 만들고, 두 상대의 각 선택을 전부 조합한다. 조합마다 선공·타깃·명중·1타 KO를 결합하고, 두 피해 구간 합산을 64단계 적분한다. `Σ_i Σ_j p_i p_j × max(K_plain, K_max1, K_max2)` 구조다.

대체: 이미 만들어진 `scores.moves`를 상수 입력으로 읽는다. 기술 메타데이터는 공개 기술·정규화 추론 슬롯·공개 후보 풀 순서로 읽어 추론 기술의 광역 타깃·우선도·Max 위력을 잃지 않는다. 같은 판의 일반 공격은 피해 배율도 다시 계산하지 않는다. 방어 메커니즘 등 판이 바뀌거나 상대 다이맥스를 읽을 때만 위 `F` 비율로 구간을 조정한다. 새 공격 후보·정밀 전술 피해·피해 롤·KO 누적표를 요청하지 않는다. 각 선택의 선공·행동 가능성·타깃·명중을 반영한 도달 확률을 `l_i`라 한다. 상대 슬롯별 도달 조건부 평균 피해를 구하고, 그 평균 이하/초과의 두 묶음으로 나눈다. 각 묶음에서:

```
L = Σ p_i × l_i
대표 min,max = Σ(p_i × l_i × min_i,max_i) / L
Q = Σ p_i × 개별 1타 KO 위험
```

비공격 선택은 `l_i=0`, `L=0`이면 대표 구간도 0이다. 기존 표에 없는 예측 공격은 그 표에서 가장 큰 1타 KO 위험의 공격을 쓴다. 표 자체가 비면 새 정밀 표를 생성하지 않고 비어 있음을 내부 기록에 남긴다. 기술을 모르는 경우에도 표에 기록된 실제 우선도를 유지한다.

각 슬롯의 두 대표 구간을 최대 네 쌍으로만 조합한다. 미도달/한쪽만 도달은 합산 확률의 간단식으로 처리한다. 기술 선택 수가 늘어도 대표 쌍은 최대 네 개다. 두 개의 약한 공격이 함께 KO하는 경우를 유지한다. 균등 구간 합산 CDF는 반복 적분 대신 다음 닫힌 식이다.

```
x = HP − min1 − min2, u = max1−min1, v = max2−min2
P(D1+D2 < HP) = [x+² − (x−u)+² − (x−v)+² + (x−u−v)+²] / (2uv)
```

폭 0인 구간은 단일 값/단일 구간 식으로 처리한다. 일반 대표 조합·첫 슬롯만 다이맥스·둘째 슬롯만 다이맥스의 최대 위험을 읽어 상대 두 마리 동시 다이맥스를 허용하지 않는다. HP를 특정 값으로 만드는 기술은 기존처럼 합산 KO 확대에서 제외한다. 마지막 `행동 확률 = 행동 가능 여부 × (1−KO 확률)`을 각 행동 자신의 식에 적용한다.

잃는 정보: 같은 묶음 안 기술/타깃/우선도 사이의 선택별 상관관계. 낮은 피해·높은 피해 묶음의 확률은 따로 유지하지만 모든 기술 분포를 그대로 보존하지는 않는다. 구간을 합친 뒤 최대 다이맥스를 읽기 때문에 기존의 조합별 최대값 평균과도 다르다. 치명타·다중 타격·HP 의존 스크립트의 정확한 분포는 재생성하지 않는다.
