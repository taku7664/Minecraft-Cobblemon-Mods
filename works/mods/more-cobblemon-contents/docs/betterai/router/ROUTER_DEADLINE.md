# Better AI Router 판단 마감 결정

| 항목 | 값 |
|---|---|
| Status | `shared` |
| Effective | 2026-08-19 |
| Obsoletes | `DESIGN.md`·`HUMANLIKE.md`의 10초 절대 상한, 폐기된 15초 마감 결정(2026-08-19) |
| Scope | 일반 싱글·더블 Brain 판단의 공용 절대 마감과 Better AI Router 설정 상한 |
| 주 독자 | 빡대리님과 본체 AI 계약·Better AI 구현 담당자 |

## 1. 후속 계약

- 본체가 발급하는 일반 Brain 판단의 절대 마감은 요청 생성부터 최대 20초여야 한다(MUST).
- Better AI의 `timeoutMillis`는 1,000~20,000밀리초를 허용해야 한다(MUST).
- 새 설정 파일의 안전 기본값 10,000밀리초는 유지해야 한다(MUST). 운영자가 20,000밀리초를 명시하면 본체 공용 마감과 Router HTTP 제한이 이를 잘라내서는 안 된다(MUST NOT).
- 대기열에서 보낸 시간은 같은 20초 예산에 포함해야 하며 HTTP 시작 뒤 새 20초를 추가해서는 안 된다(MUST NOT).
- Router와 로컬 Brain 동시 시작, 늦은 응답 폐기, Router→로컬→본체 기준선→비상 행동 폴백은 유지해야 한다(MUST).

## 2. 이전 10초·15초 조항 종료

2026-08-19부터 `DESIGN.md`와 `HUMANLIKE.md`의 10초 절대 상한, 그리고 같은 날 잠시 적용했던 15초 절대 상한은 이 문서가 대체한다. 10초는 새 설정의 기본값으로만 남으며, 10초나 15초를 현행 최대치로 병행 해석해서는 안 된다(MUST NOT). 이 변경은 로컬 Brain 점수식, Router 프롬프트, 공개 정보 경계, 합법 행동 검증과 API 키 보안 경계를 바꾸지 않는다(MUST NOT).

## 3. 채택하지 않은 대안

- Better AI JSON만 20,000으로 바꾸는 방식은 본체 공용 마감이 먼저 결과를 폐기하므로 채택하지 않았다.
- 본체 상한만 늘리고 설정 검증을 15,000에 두는 방식은 운영값을 읽지 못하므로 채택하지 않았다.
- 새 설치 기본값까지 20,000으로 올리는 방식은 사용자가 명시하지 않은 서버에서 지연 체감을 늘리므로 채택하지 않았다.

## 4. 검증 계약

- 20,000밀리초를 허용하고 20,001밀리초를 거부하는 설정 회귀 테스트가 있어야 한다(MUST).
- 본체 공개 판단 상한이 20,000밀리초임을 고정하는 테스트가 있어야 한다(MUST).
- 실제 20초 응답·시간 초과·폴백은 게임 전투에서 별도로 검증해야 한다(SHOULD).
