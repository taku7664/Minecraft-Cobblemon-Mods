# Better AI 기술·특성·도구 반영 체크리스트

기술·특성·도구 효과가 AI가 그 행동에 매기는 점수에 실제로 들어가는지 하나씩 확인한 목록이다. 점검 기준은 사용자가 정했다. 예를 들어 자기과신이 "된다"는 말은, 공격으로 상대를 KO할 때 공격+1을 얻는 값이 그 공격의 점수에 붙는다는 뜻이다. 데이터나 상태 계산에만 있고 점수가 그 값을 읽지 않으면 "된다"로 치지 않는다.

## 점검 범위와 기준

- **기준 코드:** `main` `6a715d557`(2026-10-21 15:52). 이 시점에도 다른 세션이 같은 코드를 고치고 있었다. 개발 서버에 들어 있는 `4c34d7b5a`와는 다를 수 있다.
- **기준 경로:** 실제 게임의 상급·보스 싱글. 더블에서 다르면 따로 적었다.
- **실제 게임에서는 탐색이 꺼져 있다.** `MoreCobblemonContentsBetterAi.kt:95`가 브레인을 `LocalTacticalBrain(searchless = true)`로 등록한다(직접 확인). 그래서 점수는 한 턴 기본 점수, 규칙 보정, 추첨 세 단계로만 정해진다. Showdown 엔진 탐색과 한 턴 결과 투영기(`PublicSingleTurnProjector`)는 점수에 거의 쓰이지 않는다. 투영기를 부르는 곳은 싱글 방어 가치(`LocalSinglesProtectReturn.kt:108`) 하나이고, 나머지 두 곳은 꺼져 있다(직접 확인).
- **꺼진 스위치:** `itemTransitionValue = false`(도구 효과 평가), `evolvingMatchups = false`(반복 사용·턴 경과 매치업), `leafPersistentStageValue = 0.0`(`evaluation/LocalDecisionTuning.kt`, 직접 확인).
- **고정 20점:** 어떤 평가기에도 걸리지 않는 변화기는 일반 값 20을 받는다(`evaluation/LocalNonDamagingMoveEvaluator.kt:137-141`, 직접 확인). 아래 표의 "20점"은 효과를 계산하지 않는다는 뜻이다.
- **점검 방법:** 코드를 읽어 확인했다. 실제 판단 기록이나 재생으로 확인한 항목은 없다. "직접 확인"이라고 적은 항목은 원본 코드를 열어 대조했다. 나머지는 조사 에이전트가 읽은 결과이고, 원본과 대조하기 전이다.

판정 표시는 다음과 같다.

| 표시 | 뜻 |
|---|---|
| ✅ | 반영: 결과가 점수에 들어간다 |
| △ | 부분: 일부만 들어가거나 조건이 붙는다 |
| ⬜ | 투영만: 상태 계산에는 있지만 점수가 읽지 않는다 |
| ❌ | 없음: 계산하는 곳이 없다 |

## 랭크업 변화기

랭크업 점수는 사실상 `matchup/LocalSetupGate.kt` 하나로 정해진다. 랭크를 올린 뒤 1:1에서 이기고(승률 0.7 이상), 그 랭크업이 어떤 상대와의 교환에서 KO 타수·버티는 타수·선공 가운데 하나라도 바꿀 때만 200 × 스윕 보너스를 준다. 아니면 0이다. 그래서 1:1 교환 표에 나타나는 효과는 반영되고, 표 밖의 효과(필드, 교체로 넘기기, 도구 발동, 대타)는 거의 빠진다.
