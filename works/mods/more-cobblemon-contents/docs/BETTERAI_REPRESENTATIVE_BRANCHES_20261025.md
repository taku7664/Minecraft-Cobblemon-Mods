# 피격 분기·교체 후 대면 단순화 (2026-10-25)

기준 main `2cf7bd873`, 작업 `codex/betterai-entry-healblock` / 1b39. 빡대리는 더블 분기를 대표 상수·간단식으로 줄이고 싱글과 비슷한 시간, 최대 2배를 요청했다. 순서 교대 측정에서 더블 223ms 수준이 나온 뒤 “그정도면 ㄱㅊ”라고 수용했다. 평균 약 2.12배이며 엄밀한 2배 상한을 달성했다고 쓰지 않는다. 모든 전투·모든 턴의 시간 상한도 보장하지 않는다.

## 소유권과 설정

새 옵션 `single.representativeHitOutcomes`, `double.representativeHitOutcomes`, `single.simpleSwitchContinuations`, `double.simpleSwitchContinuations`은 모두 기본 false다. 기존 키의 의미를 바꾸거나 새 근사를 자동으로 켜지 않았다. JSON과 한국어·영어 Mod Menu에서 싱글·더블별로 설정한다. 옵션 수가 늘어 화면에서 잘리지 않도록 네 행씩 두 페이지로 표시한다. 서버 JSON은 다음 새 전투부터 읽으며 기존 전투는 설정 스냅샷을 유지한다. 실제 사용자 설정·VPS·제품 JAR은 수정하지 않았다.

현재 행동의 `LocalStatStageMarginalEvaluator`와 랭크 평가식, 기본 공격의 피해·KO 점수, 후보 생성과 선택 규칙은 변경하지 않았다. 분기에서 발생한 반응 랭크의 평가식도 기존 것을 사용하되 대표 피해에 따라 반응 발생 확률과 상태는 달라질 수 있다. 순위가 나온 뒤 점수를 빼거나 다른 종류 행동의 점수에 보정하지 않는다.

## 기존 계산과 대체 계산

`LocalMoveImpactProjector`의 정밀 경로는 피해 난수 위치·급소·타격 수를 나누고, 실제 반응 판과 반응 없는 본체 판을 각각 투영한다. 연속기의 접촉 상태이상, 대타 잔여 HP 가설도 타격마다 판을 나눈다. 광역기의 다음 대상, 아군 두 번째 기술과 두 행동 순서에 앞선 상태가 다시 곱해진다. 같은 최종 상태는 합치지만 이미 만든 중간 판과 계산은 되돌릴 수 없다.

`representativeHitOutcomes`를 켜면 다음과 같이 바뀐다.

- 피해 난수는 KO/생존 분류별 조건부 평균으로 합친다. 일반적인 한 대상의 수치 결과는 KO·생존·빗나감 최대 세 종류다. 분류 확률의 합과 명중 확률은 보존한다. 대타·열매 임계치의 세부 난수 분포는 근사한다.
- 별도의 무작위 급소 피해 재계산은 하지 않는다. 일반 급소의 기대 피해는 기존 피해에 `1 + pCritical × (1.5 - 1)`을 곱한다. 확정 급소는 원래 피해 계산을 읽는다. 분노의경혈은 반응이 달라지므로 급소 여부를 별도 분류하지만 무작위 급소 피해는 여전히 1.5배 근사다. 급소가 방어 랭크를 무시하는 효과나 특수 급소 배율의 세부 재계산은 잃는다.
- 타격 수 분포는 반올림한 기대 타격 수 하나로 바꾼다. 타격마다 명중을 검사하는 기술은 첫 타 명중 조건부 기대 횟수를 사용한다. 타격 피해는 대표 총 피해를 횟수로 나누며 타격 사이의 정밀 피해 재계산을 호출하지 않는다.
- 헬멧·까칠한피부·지구력·열매 등 확정 반응은 각 타격에 실행한다. 접촉 확률만 마지막에 누적한다. 한 효과의 발동률은 `1 - (1-p)^n`, 배타적인 여러 상태는 `1-(1-Σp)^n`을 각 상태의 확률 비율로 나눈다. 예: 30% 효과의 5타 누적 확률은 83.193%다. 발동 시점과 그로 인한 타격 중간 상호작용은 근사한다.
- 잔여 HP가 범위로만 알려진 대타는 그 범위의 중간값 하나로 읽는다. 확정 HP 대타와 타격별 파괴 처리는 공통 메커니즘을 사용한다.
- 실제 HP·KO 반응은 반응 없는 본체 판과 비교해 가격을 매기고, 반응 랭크는 기존대로 때리기 전 HP 판에서 평가한다. 생구의 기술당 한 번 비용과 공동 열매 소비도 기존 소유권을 유지한다.

`simpleSwitchContinuations`의 기존 식은 결과 판마다 `pairMatchup`으로 양측 공격·피해·KO 표·대면을 재계산한 뒤 분기 확률로 합산한다. 새 식은 이미 만든 대면의 두 대표 공격을 고정한다. 기존 피해 구간을 실제 능력치·상태 보정 배율로 환산하고 `평균 피해 × 명중률`, `ceil(잔여 HP / 평균 피해)`, 선공 확률로 전후 대표 대면을 계산한다. 이후 아래 변화량만 기존 대면에 반영한다.

```
W = clamp(base.W + representativeAfter.W - representativeBefore.W, 0, 1)
Hwin = clamp(base.Hwin + representativeAfter.Hwin - representativeBefore.Hwin, 0, 1)
Hloss = clamp(base.Hloss + representativeAfter.Hloss - representativeBefore.Hloss, 0, 1)
score = W × (0.5 + 0.5 × Hwin) - (1-W) × (0.5 + 0.5 × Hloss)
```

피격으로 죽는 분기는 기존 생존 확률·사망 점수 처리를 유지한다. 위 식은 교체 대면 자신의 계산식 안에서 실행한다. 다른 행동에 감점을 전가하지 않는다. HP·승률·점수를 함께 갱신하여 `afterEntry`의 내부 값도 일관되게 유지한다.

초안은 대표 대면의 절대값으로 기존 대면을 덮어썼다. 메타그로스 장면에서 고정 대표 공격의 피해가 0인 값을 읽어 기존 유리한 대면을 패배로 뒤집었고 선택도 달라졌다. 이를 그대로 채택하지 않고 위 변화량 방식으로 수정했다. 입력이 같으면 기존 대면을 유지하는 회귀 검사를 추가했다.

에이스 보관 표의 키에는 전체 튜닝 값을 포함했다. 설정이 다른 새 전투가 이전 설정으로 계산한 표를 가져오지 않도록 한다. 보관 개수와 계산 종료 시 임시 판 참조 해제 정책은 유지한다.
