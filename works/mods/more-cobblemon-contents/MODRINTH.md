# More Cobblemon Contents Core

The shared foundation for Cobblemon battle facilities: managed battles, tactical AI, Battle Points, a reward shop, records, the battle hub and hologram terminals. Add content with MCC addons.

## Installation

Install on **both the server and every connecting client**. Supports Minecraft Java 1.21.1 and Java 21, with Fabric Loader 0.19.5+, Fabric API, Fabric Language Kotlin 1.14.1+kotlin.2.4.20+ and Cobblemon 1.8.1 or newer, below 1.9.0.

The core requires Mega Showdown `1.2.0+1.8.1+1.21.1-release`. Install the MCC content addons you want to play. The core bundles its UI kit.

Open the hub with `/mcc` or a content terminal. The server controls which tabs are available.

## Configuration

Server administrators configure hub access in `config/more-cobblemon-contents/hub_tabs.json` and wiki integration in `wiki.json`. BP shop content comes from data packs. There is no separate Mod Menu configuration screen in the current core.
