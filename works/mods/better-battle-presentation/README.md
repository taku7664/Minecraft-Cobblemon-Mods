# Cobblemon: Better Battle Presentation

Standalone battle-presentation effects for Cobblemon, beginning with Dynamax atmosphere and sky effects for Mega Showdown.

- Mod ID: `cobblemon_better_battle_presentation`
- Side: client and server
- Requires: Fabric API, Cobblemon 1.8.1, and Mega Showdown 1.2.0 for Cobblemon 1.8.1

## Build

Run from the repository root:

```powershell
.\gradlew.bat :better-battle-presentation:build
```

The JAR is written to `better-battle-presentation/build/libs`.
