## 발견한 오류와 수정

1. **물속·수면 9종의 스폰 차단:** `natural` 프리셋의 `neededBaseBlocks`는 `GroundedTypeSpawningCondition`에만 존재한다. 물속·수면 조건 클래스에서는 무시되어, 프리셋의 경작지 제외 조건이 빈 조건으로 남는다. `SpawnDetailPreset.resolveCondition/apply`와 `SpawnDetail.isSatisfiedBy` 처리에 따라 빈 제외 조건이 후보를 차단한다. 가이오가·루기아·아그놈·엠라이트·유크시·마나피·피오네·굽이치는물결은 `water`, 네더 용암 표면의 위유이는 `lava`로 교체했다.
2. **프리져의 엔드 출현:** `#cobblemon:is_cold` → `#c:is_cold` → `#c:is_cold/end` 경로에 바닐라 엔드 바이옴 5종이 포함된다. 바이옴 조건만 있고 차원 제한이 없어 엔드에서도 후보가 됐다. 프리져를 오버월드로 제한했다.
3. **차원 범위 미명시 95종:** 기존 문서에 지정된 엔드·네더·복수 차원 출현은 보존하고, 나머지 종은 오버월드로 한정했다. 기존 고대·미래 8종의 명시 차원은 그대로다. 향후 공통 태그 확장으로 다른 차원에 새 후보가 생기는 것을 막는다.
4. **안내 문서의 오래된 등급 설명:** 실제 코드는 등급을 스폰·포켓내비·포획에 모두 적용한다. 포획만 제한한다는 설명을 정정했다.
5. **위키 생성기:** 명시한 바닐라 차원 ID를 번역하고, 명시 차원이 있으면 바이옴 이름으로 차원을 덧붙이지 않도록 수정했다.

main에 먼저 반영된 `legendary` 전용 버킷과 0.002 가중치 변경은 유지했다. 검수 시점의 운영 JAR은 이전 `ultra-rare` 버킷을 사용한다. 수정 소스를 빌드하는 것과 운영 서버에 적용하는 것은 별도다.
