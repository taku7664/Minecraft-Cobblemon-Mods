# Cobblemon UI

**코블몬 전투 화면을 더 보기 쉽고 편하게 바꿔 주는 클라이언트 모드입니다.**

전투 명령, 기술 선택, 포켓몬 교체, 대상 선택, 체력 표시와 대화창을 하나의 UI로 정리합니다. 키보드와 마우스로 조작하고, 전투 정보를 확인하거나 이전 전투 기록을 다시 읽을 수 있습니다.

## 주요 기능

- 전투 명령·기술·교체·대상 선택 화면과 기권 확인창 개선
- 양 팀의 공개된 정보, 날씨·필드·진영 효과와 능력 변화 표시
- 기술의 위력·명중률·PP·상성·급소 정보 툴팁
- 포켓몬 초상화와 턴 구분이 있는 스크롤 전투 기록
- 챔피언스·가라르 배틀 테마, 선택 가능한 전투 진입 연출
- 공통 대화창의 둥근 창·픽셀 프레임 스타일과 여섯 가지 색상
- 한국어·영어 UI

## 설치

Minecraft Java 1.21.1, Fabric Loader 0.19.5 이상, Cobblemon 1.8.1, Fabric API, Fabric Language Kotlin 1.12.0 이상, Java 21 이상이 필요합니다. 클라이언트의 `mods` 폴더에 설치합니다. 전용 서버에는 설치할 필요가 없습니다.

게임 안에서 설정하려면 Mod Menu와 Cloth Config를 함께 설치하고 **Mods → Cobblemon UI → 설정**을 여세요. 설정 파일은 사용 중인 프로필의 `config/cobblemon_ui.json`입니다.

## 기본 조작

| 키 | 기능 |
| --- | --- |
| 방향키 또는 W/A/S/D | 전투 선택지 이동 |
| Z | 선택·대화 진행 |
| X | 취소·뒤로 |
| Tab | 전투 정보 열기·닫기 |
| 왼쪽 Shift | 전투 기록 열기·닫기 |

전투 기록에서는 휠·방향키·Page Up/Down·Home/End로 이동할 수 있습니다. 키 설정은 Minecraft 조작 설정에서 변경할 수 있습니다.

## 설정과 사용 범위

배틀 테마, 전투 진입 연출, 팀 미리 보기, 전투 정보, 기술 툴팁, 피해·회복 퍼센트, 글자 크기와 툴팁 세부 정보를 설정할 수 있습니다. 글자 배율은 기본 1.0이며 0.5~2.0 범위를 지원합니다.

상대 스피드 범위는 추정치이며, 아직 공개되지 않은 정보나 효과의 남은 시간을 정확한 값으로 보장하지 않습니다. 일반 인벤토리·제작 화면은 바꾸지 않습니다. 다른 모드가 이 UI 라이브러리를 사용해 제공하는 화면은 해당 모드를 별도로 설치해야 사용할 수 있습니다. 같은 전투 화면을 교체하는 다른 모드와의 호환성은 확인되지 않았습니다.
