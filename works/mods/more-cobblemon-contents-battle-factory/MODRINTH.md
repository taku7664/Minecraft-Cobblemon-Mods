# More Cobblemon Contents: Battle Factory

Build a rental team and challenge the Battle Factory. This MCC addon provides rental Pokémon selection, team swaps and battle progression, integrated with the MCC core's rewards and records.

## Installation

Install on **both the server and every connecting client**. Supports Minecraft Java 1.21.1 and Java 21, with Fabric Loader 0.19.5+, Fabric API, Fabric Language Kotlin 1.14.1+kotlin.2.4.20+ and Cobblemon 1.8.1 or newer, below 1.9.0.

Requires More Cobblemon Contents Core 0.1.x and its dependencies. This addon does not run on its own.

Open the hub with `/mcc` or a content terminal. The server controls which tabs are available.

## Configuration

Players use the content's hub screen. Administrators customize content through server data packs. There is no separate Mod Menu configuration screen.
