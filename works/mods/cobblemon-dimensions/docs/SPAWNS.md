# 차원 스폰표

`works/tools/cobblemon-dimensions/gen_dimensions.py`가 스폰 데이터와 함께 만드는 표입니다. 직접 고치지 말고 스크립트를 고친 뒤 다시 돌립니다.

등급은 Cobblemon 스폰 버킷입니다(흔함·가끔·드묾·아주 드묾). 같은 등급 안에서는 가중치가 같습니다. 바닐라 몹은 나오지 않습니다.
