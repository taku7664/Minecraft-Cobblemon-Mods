## [2026-10-06 07:05] 차원별 지형 시드, 고대·미래 하늘·안개 연출

- 문제: 세 차원 모두 Terralith 오버월드 지형 함수를 월드 시드 그대로 써서, 같은 좌표면 오버월드와 지형 모양이 같았다(코드 구조로 판단, 오버월드와 직접 비교는 안 함).
- 사용자 결정: 시드 믹스인 → 바이옴 파티클 → 하늘 장식 순서로 진행. 울트라스페이스 짙은 안개처럼 고대·미래에도 시야를 바꾸는 분위기 연출을 원했다(시야 제한까지는 아님).
- 시드: `ChunkMapSeedMixin`이 우리 차원의 `RandomState` 시드를 `월드 시드 XOR (차원 ID 해시 × 상수)`로 바꾼다. 지형과 바이옴이 같은 시드라 서로 계속 맞고, 구조물 배치는 월드 시드 그대로. 노이즈 파일 복사 방식은 Terralith 함수 수백 개를 복사해야 해서 기각. 캡처에서 고대·미래 같은 좌표(1200, 900) 지형이 서로 다르게 나와 적용을 확인했다(전에는 둘 다 같은 Terralith 지형이었다).
- 서버 열기 전에만 바꿀 수 있다. 사용자의 싱글 테스트 월드 `client/saves/새로운 세계`에 세 차원 청크가 이미 있어서, 그 월드에선 옛 청크와 새 청크 사이에 경계가 생긴다. 지울지는 사용자 판단.
- 안개: `FogRendererHazeMixin`이 지형 안개 시작·끝을 `DimensionLook.Haze`(렌더 거리 비율, 최소 끝 거리, 바이옴별 끝)로 바꾼다. 물·용암·실명·어둠·울트라 짙은 안개 상황은 건드리지 않는다. 바이옴이 바뀌면 2초에 걸쳐 바뀐다. 고대는 (0.15, 0.9, 최소 64칸, 밀림 0.7, 화산 0.6), 미래는 (0.3, 0.9, 64칸, 네온 숲 0.65). 고대 첫 값(0.05, 0.7)은 캡처에서 너무 짙어 낮췄다.
- 하늘: `LevelRendererSkyMixin`. 고대는 태양 텍스처 교체(`textures/environment/ancient_sun.png`, 스크립트로 그린 64px 붉은 원반+후광)와 크기 30→60. 미래는 `SkyExtras` 빛의 고리(50도 기운 대원, 띠 3개, 가장자리 투명한 가산 혼합, 지평선 근처 페이드)와 낮 별(`getStarBrightness` 최소 0.45), 밤 안개·하늘 시안 잔광(`nightGlow` 0.18). 첫 고리는 가장자리가 딱딱해 UI 줄무늬처럼 보여 그라데이션으로 바꿨다.
- 파티클: 생성 스크립트 `PARTICLES`. 고대 화산 ash, 밀림 spore_blossom_air, 사막 white_ash, 미래 네온 숲 warped_spore, 수정 end_rod, 강철·평원 electric_spark.
- 캡처 하네스: 샷에 시간(`time`) 추가, `ancient-sun`(해돋이), `future-ring`, `future-night` 추가.
- 빌드 성공, JAR 무결성 확인, 커밋 e69fbc25. 서버·클라이언트가 꺼진 상태에서 두 곳에 배치(SHA-256 앞자리 d5827400). 서버는 켜지 않았다. 실게임(지상 높이) 확인과 Iris 등 셰이더팩과의 충돌 여부는 미확인. 캡처는 모두 지상 30~60칸 위 시점이라 지상에서는 안개가 더 옅어 보일 것으로 예상.

## [2026-10-06 03:50] 울트라홀, 고대·미래 차원 구성, 일반 포켓몬 스폰표

- 사용자 목표(/goal): 울트라홀 제작(레퍼런스 참고), 일반 리그 사천왕 격파 후에만 진입("아직 들어갈 자격이 없는 것 같다." 빨간 채팅), 일반 포켓몬 스폰과 스폰표, 고대·미래 차원을 임의로 구성해서 캡처로 보여 주기.

- 진입 자격: `LeagueRanks.of() == CHAMPION`(일반 리그 사천왕 4연전 + 챔피언, 저장 데이터의 `champion`). League Challenge 미설치면 누구나, 설치됐는데 리그 카탈로그가 없으면 아무도 못 들어간다. `/cdim` 명령어는 자격을 따지지 않는다.
- 울트라홀 구현: `UltraWormhole` 엔티티(저장 안 함, 반경·수명·귀환 여부 동기화), 열리고 닫히는 2초 동안은 진입 안 됨. 렌더링은 텍스처 없이 `RenderType.lightning()` 가산 혼합: 흰 중심, 무지갯빛 테두리(가장자리 일렁임), 소용돌이 팔 4개, 큰 홀은 후광 고리 2개. 레퍼런스는 게임 속 울트라홀(흰 중심, 후광 고리, 소용돌이 에너지) 설명. 빈도는 `config/cobblemon-dimensions.json`(`WormholeSettings`).
- 고대·미래: 울트라스페이스처럼 Terralith 배치표를 바이옴 5개씩으로 바꿨다. 고대 = 고대 바다·원시 밀림·고대 사막·태고의 화산·고대 초원, 미래 = 미래 바다·강철 산맥·수정 지대·네온 숲·미래 평원. 지형 설정은 Terralith 오버월드 설정을 복사하고 표면 규칙만 이 모드 것(기반암 바닥, 심층암 층, 바이옴별 윗면·아랫면 블록, 물 밑엔 잔디 대신 흙)으로 바꿨다. 바다와 물이 있다.
- 스폰: 세 차원 모두 바이옴별 일반 포켓몬(Cobblemon 1.8.1 구현 종만, 전설·환상·울비·패러독스 제외). 미구현이라 뺀 후보: 메테노, 목도리키텔, 하랑우탄, 내던지는몽, 전지충이, 투구뿌논, 일레도리자드. 울트라 바이옴에 Cobblemon 바이옴 태그를 달지 않고 전용 스폰 풀을 써서 jbro 전설이 섞이지 않는다. 패러독스·코라이돈·미라이돈 스폰은 아직 없다(Legend 연동 때 함께).
- 생성 스크립트: `gen_ultra_space.py`를 지우고 `gen_dimensions.py`로 합쳤다. 바이옴, 배치표, 고대·미래 지형 설정, 스폰 풀, `docs/SPAWNS.md`를 한 번에 만든다. 울트라스페이스 결과물은 예전 스크립트와 똑같이 나오는 것을 확인했다.
- 개발 실행: Terralith는 Lithostitched가 필요하다(서버에는 `lithostitched-1.8.0-fabric-21.1.jar`가 있음). `modLocalRuntime`으로 서버 mods 폴더의 두 jar와 Cobblemon을 넣었다. Terralith의 `data/minecraft/dimension/overworld.json`은 Lithostitched가 있으면 로드되지 않는 파일이지만, 우리는 배치표 데이터만 읽어 복사하므로 상관없다.
- 캡처 하네스: `DimensionCaptureHarness`(`-Dcobblemon_dimensions.capture=true`, `runCapture`). 새 월드를 코드로 만들어 실험적 설정 경고를 피하고, 포탈·울트라홀·고대 3장·미래 3장·울트라 2장을 찍고 종료한다.
- 캡처하면서 겪은 문제: (1) Terralith → Lithostitched → Apollib → json5가 jar 안의 jar로 들어 있어 개발 실행에서 못 찾음. 빌드 스크립트가 재귀로 꺼낸다. (2) 차원 이동이 서버 스레드에서 청크를 만드느라 오래 걸려, 이동 전에 찍혔다. 서버 쪽 도착 신호와 클라이언트 차원 일치를 기다린다. (3) 새 run 폴더 첫 실행의 접근성·언어 화면(사용자가 직접 눌러 줌)과 포커스를 잃었을 때의 일시정지로 멈췄다. 하네스가 둘 다 넘긴다. (4) 의존성 누락으로 실패한 Fabric 실행은 오류 창을 띄운 채 남아 로그 파일을 잡는다. 다시 띄우기 전에 끈다.

## [2026-10-06 03:20] 울트라스페이스 지형을 더 기괴하게

- 사용자 확인(실게임): 섬 지형·바이옴 전환·침대 금지 동작 확인. 0, 0 근처가 큰 울트라데저트라 처음엔 사막만 보였다. 사용자는 지금 지형에 만족하면서도 더 기괴했으면 했다.
- 사용자 결정: 제안 1(밑면을 뜯겨 나간 바위처럼), 2(높은 곳 작은 섬 층), 3(지형 뒤틀기)은 아주 약하게.
- 침대 메시지: 액션바 대신 채팅에 빨간 글씨 "불가사의한 힘으로 잘 수 없다."(사용자 지정 문구). 리스폰 앵커는 별도 문구.
- 구현: `worldgen/density_function/ultra_space/`로 나눴다. 값 조절은 여기서 한다.
  - `rough`: 세로로 늘어진 3D 노이즈(`ultra_drips`, y_scale 0.2) ×0.4. 본섬 마스크와 하늘 섬에 더해 밑면을 종유석처럼, 가장자리를 들쭉날쭉하게.
  - `island_mask`: 기존 본섬 마스크 + `rough`.
  - `sky_islands`: Y 230±25(높이 노이즈 `ultra_sky_height`)에 렌즈 모양 작은 섬(`ultra_sky_islands`, 64칸 주기). 두께는 -0.06 계수로 정한다.
  - `warp`: Terralith 밀도에 더하는 3D 노이즈 ×0.07. 키우면 Terralith 고유 지형이 흐려진다.
  - `final_density = max(min(Terralith + warp, island_mask), sky_islands)`.
- 이미 생성된 청크는 예전 지형 그대로라 새 청크와 경계가 생긴다. 깔끔하게 보려면 새 월드나 울트라스페이스 차원 폴더를 지워야 하는데, 지우는 건 사용자 판단.
- 빌드 성공, JAR 무결성 확인. 커밋 4a37bae6의 JAR(SHA-256 앞자리 e77d1688)을 서버에 먼저, 사용자가 게임을 끈 뒤 클라이언트에 배치. 실게임 검증 안 함(값은 감으로 정했다).

## [2026-10-06 02:09] 기획: 울트라스페이스·고대·미래 차원

### 사용자 결정

- 새 모드로 만든다. 폴더와 모드 ID는 `cobblemon-dimensions`/`cobblemon_dimensions`. Modrinth에 같은 slug의 "Cobblemon: Dimensions"(모드팩)가 있지만 사용자가 괜찮다고 했다.
- 차원 3개: 울트라스페이스, 고대(`ancient`), 미래(`future`). ID는 원작 분류(Ancient/Future Paradox)와 맞으니 그대로 쓰고, 게임에 보이는 이름은 따로 정한다(미정).
- 귀환: 죽거나, 떨어지거나(울트라스페이스), 포탈로만 돌아간다. 파티 전멸은 귀환 조건이 아니다.
- 이 차원들에서는 무조건 인벤세이브. 게임룰은 전역이라 차원 한정 처리를 코드로 넣어야 한다(저장소 모드에 keepInventory 처리 없음 확인).
- 침대는 이 차원들에서 절대 못 쓴다. 리스폰 앵커·네더 포탈도 같이 막는 쪽으로 검토.
- 저중력은 울트라스페이스만.
- 지형: 울트라스페이스는 픽셀몬처럼 섬 기반, 고대·미래는 오버월드 기반. 고대·미래의 세부 바이옴 구성은 보류.
- 울트라스페이스는 픽셀몬처럼 전용 바이옴(울트라 데저트, 울트라 정글 등)으로 만들고, Terralith의 특수 지형을 적극 활용한다.
- 진입: 울트라스페이스는 실제 울트라홀(하늘에 랜덤으로 열리는 방식, 구현 방법은 더 찾아야 함). 고대·미래는 엔드 포탈 구조에 틀 블록과 포탈 면 색만 바꾼 것, 점화는 부싯돌과 부시. 틀 블록은 고대도시 블록 느낌(고대)·금속(미래)으로, 철 블록 12개는 너무 비싸서 기각. 나중에 사용자가 바꿔 달라고 하면 바로 바꿀 수 있어야 한다. 울트라홀을 여는 포켓몬 기능은 넣지 않는다.
- 스폰: 울비는 픽셀몬 스폰 정보를 따른다. 패러독스는 고대·미래 차원에서 희귀 스폰. 차원에는 일반 포켓몬도 나온다.
- 코라이돈·미라이돈은 각각 고대·미래 차원에서만 나오고 오버월드에서는 빠진다. 엔트리 조건은 패러독스 아무거나(사용자가 고대·미래 구분은 하지 않기로 함, 라벨 `paradox`로 판정).
- 울비·패러독스도 Legend 시스템(등급 제한, 공지, 포획 기록)에 넣는다.
- 전설 패러독스 6마리를 차원으로 옮기는 일은 나머지 스폰을 추가할 때 한꺼번에 한다.
- 차원별 음악은 사용자가 구해 온다. 받으면 `better-cobblemon-music`에 연결.
- 월드보더·사전 생성, 서버 위키 갱신도 할 일에 넣는다.

### 확인한 사실

- Cobblemon 1.8.1 본체와 CCC 2.21 데이터팩에 울비(793~806)·일반 패러독스(984~995, 1005~1010) 스폰 파일이 없다. 지금 서버에서는 안 나온다.
- Cobblemon 종 라벨은 `paradox`, `ultra_beast`만 있고 고대·미래 구분은 없다. 고대·미래 목록은 직접 들고 있어야 한다.
- 광장(`jbro-policy`의 `HubReturnRule`)과 마이룸(`ReturnDimensionPolicy`)은 차원 제한 없이 복귀 지점을 저장한다. 새 차원도 코드 변경 없이 저장된다. 단, 울트라스페이스 섬 위에서 저장할 때 `SafeLanding.groundY`가 허공을 어떻게 처리하는지는 실게임에서 확인해야 한다.
- 서버에 `/spawn`, `/home`, 웨이스톤 같은 다른 이동 수단은 없다(서버 모드 목록과 저장소 명령어 기준).
- Terralith 2.6.2는 `minecraft:overworld` 지형 설정과 density function을 덮어써서 특수 지형을 만든다. 오버월드 지형 설정을 참조하는 차원은 Terralith 지형을 그대로 받고, 섬 기반 차원은 그렇지 않다.
- Cobblemon에 비스트볼, 호박 화석과 각종 화석, 메탈코트, 업그레이드는 있고 부스트에너지는 없다.
