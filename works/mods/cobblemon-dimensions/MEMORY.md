- 구현: 차원 3개 등록, 울트라스페이스 섬 지형·바이옴 6개·울비 스폰, 저중력(플레이어만, `generic.gravity` ×0.2), 차원 바닥 아래로 떨어지면 진입 위치로 귀환, 침대·리스폰 앵커 사용 막음, 진입 위치 저장(`EntryPoints`, 광장·마이룸 진입은 덮어쓰지 않음), 확인용 `/cdim go|return`.
- 섬 지형: `min(Terralith final_density, 섬 마스크)`. 마스크는 2D 노이즈 `ultra_islands`와 Terralith `depth`로 만들어서, 섬이 지표 아래로 노이즈 값만큼 두껍게 남는다. 해수면 -64, 대수층 끔(허공에 물이 차지 않게). 섬 크기·두께는 `noise_settings/ultra_space.json`의 상수(-0.3, 2.0, -1.7)로 조정한다. 실게임에서 아직 본 적 없음.
- 바이옴 배치: `works/tools/cobblemon-dimensions/gen_ultra_space.py`가 Terralith 오버월드 배치표 1699개 항목(지하 바이옴 제외)의 바이옴 이름만 울트라 바이옴으로 바꾼다. 항목 수는 포레스트 630, 플랜트 417, 데저트 279, 정글 140, 딥시 121, 크레이터 112. 항목 수가 면적과 같지는 않아서 실제 비율은 실게임에서 봐야 한다.
- 울트라 바이옴에는 Cobblemon 바이옴 태그를 달지 않았다. 일반 포켓몬은 안 나오고 울비만 나온다. 태그를 달면 태그 기반 전설 스폰(jbro 전설 풀)도 같이 들어오므로 사용자 결정 필요.
- 고대·미래: 바이옴 구성 보류라 `minecraft:overworld` 지형과 프리셋을 그대로 쓰는 임시 차원. 오버월드 바이옴이라 Cobblemon 일반 스폰과 jbro 전설 스폰이 그대로 나온다. 사용자가 렌더링을 보려고 남겨 두라고 했다.
- 렌더링 시안(사용자 요청): `DimensionLook`(DimensionSpecialEffects)과 `ClientLevelSkyTintMixin`. 울트라스페이스는 짙은 안개·구름 없음·바이옴별 색, 고대는 호박색 틴트·낮은 구름, 미래는 보라 하늘·시안 안개·구름 없음. 후처리 셰이더는 아직 없음.
- 포탈: 엔드 포탈 규격(3x3 구멍, 틀 12개, 모서리 제외), 부싯돌과 부시로 점화. 틀 블록은 사용자가 나중에 바로 바꿀 수 있게 블록 태그로만 정한다(고대 `chiseled_deepslate`, 미래 깎은 구리 8종). 포탈 면은 엔드 포탈 렌더러 위에 `RenderType.lightning()` 색 막을 덧그린다(`TintedPortalRenderer.COLORS`). 차원 안에서 지은 포탈은 귀환용. 귀환 지점이 포탈 위면 x+4로 비켜 내린다.
- 인벤세이브: 개발 서버 `level.dat`의 `keepInventory`가 이미 true라 차원 한정 코드는 넣지 않았다. 서버 게임룰이 바뀌면 차원 안에서도 인벤이 떨어진다.
- 빌드: `:cobblemon-dimensions:build` 성공, JAR 무결성 확인, 믹스인 대상은 intermediary로 변환됨 확인. 테스트 코드 없음.
- 배포: 커밋 06a3e75b의 JAR을 `develop-product/server/mods`, `develop-product/client/mods`에 새로 배치(새 모드라 백업 없음, SHA-256 앞자리 0698bf60). 서버·클라이언트 모두 꺼진 상태에서 배치했고 서버는 기동하지 않았다.
- 실게임 검증: 안 함. 서버 기동 전이라 데이터팩 로드(지형 JSON 오류 여부)도 아직 모른다.

## [2026-10-06 02:09] 기획: 울트라스페이스·고대·미래 차원

### 사용자 결정

- 새 모드로 만든다. 폴더와 모드 ID는 `cobblemon-dimensions`/`cobblemon_dimensions`. Modrinth에 같은 slug의 "Cobblemon: Dimensions"(모드팩)가 있지만 사용자가 괜찮다고 했다.
- 차원 3개: 울트라스페이스, 고대(`ancient`), 미래(`future`). ID는 원작 분류(Ancient/Future Paradox)와 맞으니 그대로 쓰고, 게임에 보이는 이름은 따로 정한다(미정).
- 귀환: 죽거나, 떨어지거나(울트라스페이스), 포탈로만 돌아간다. 파티 전멸은 귀환 조건이 아니다.
- 이 차원들에서는 무조건 인벤세이브. 게임룰은 전역이라 차원 한정 처리를 코드로 넣어야 한다(저장소 모드에 keepInventory 처리 없음 확인).
- 침대는 이 차원들에서 절대 못 쓴다. 리스폰 앵커·네더 포탈도 같이 막는 쪽으로 검토.
- 저중력은 울트라스페이스만.
- 지형: 울트라스페이스는 픽셀몬처럼 섬 기반, 고대·미래는 오버월드 기반. 고대·미래의 세부 바이옴 구성은 보류.
- 울트라스페이스는 픽셀몬처럼 전용 바이옴(울트라 데저트, 울트라 정글 등)으로 만들고, Terralith의 특수 지형을 적극 활용한다.
- 진입: 울트라스페이스는 실제 울트라홀(하늘에 랜덤으로 열리는 방식, 구현 방법은 더 찾아야 함). 고대·미래는 엔드 포탈 구조에 틀 블록과 포탈 면 색만 바꾼 것, 점화는 부싯돌과 부시. 틀 블록은 고대도시 블록 느낌(고대)·금속(미래)으로, 철 블록 12개는 너무 비싸서 기각. 나중에 사용자가 바꿔 달라고 하면 바로 바꿀 수 있어야 한다. 울트라홀을 여는 포켓몬 기능은 넣지 않는다.
- 스폰: 울비는 픽셀몬 스폰 정보를 따른다. 패러독스는 고대·미래 차원에서 희귀 스폰. 차원에는 일반 포켓몬도 나온다.
- 코라이돈·미라이돈은 각각 고대·미래 차원에서만 나오고 오버월드에서는 빠진다. 엔트리 조건은 패러독스 아무거나(사용자가 고대·미래 구분은 하지 않기로 함, 라벨 `paradox`로 판정).
- 울비·패러독스도 Legend 시스템(등급 제한, 공지, 포획 기록)에 넣는다.
- 전설 패러독스 6마리를 차원으로 옮기는 일은 나머지 스폰을 추가할 때 한꺼번에 한다.
- 차원별 음악은 사용자가 구해 온다. 받으면 `better-cobblemon-music`에 연결.
- 월드보더·사전 생성, 서버 위키 갱신도 할 일에 넣는다.

### 확인한 사실

- Cobblemon 1.8.1 본체와 CCC 2.21 데이터팩에 울비(793~806)·일반 패러독스(984~995, 1005~1010) 스폰 파일이 없다. 지금 서버에서는 안 나온다.
- Cobblemon 종 라벨은 `paradox`, `ultra_beast`만 있고 고대·미래 구분은 없다. 고대·미래 목록은 직접 들고 있어야 한다.
- 광장(`jbro-policy`의 `HubReturnRule`)과 마이룸(`ReturnDimensionPolicy`)은 차원 제한 없이 복귀 지점을 저장한다. 새 차원도 코드 변경 없이 저장된다. 단, 울트라스페이스 섬 위에서 저장할 때 `SafeLanding.groundY`가 허공을 어떻게 처리하는지는 실게임에서 확인해야 한다.
- 서버에 `/spawn`, `/home`, 웨이스톤 같은 다른 이동 수단은 없다(서버 모드 목록과 저장소 명령어 기준).
- Terralith 2.6.2는 `minecraft:overworld` 지형 설정과 density function을 덮어써서 특수 지형을 만든다. 오버월드 지형 설정을 참조하는 차원은 Terralith 지형을 그대로 받고, 섬 기반 차원은 그렇지 않다.
- Cobblemon에 비스트볼, 호박 화석과 각종 화석, 메탈코트, 업그레이드는 있고 부스트에너지는 없다.

### 픽셀몬 9.4.1 분석 (참고만, 값·코드·에셋 복사 금지)

- jar: `develop-product/temp/pixelmon/` (git 무시 경로). 라이선스 All Rights Reserved.
- 울트라스페이스는 데이터팩 JSON 차원. 9.4.1의 `noise_settings`는 바닐라 오버월드 공식(큰 바이옴)을 거의 그대로 쓴다. 사용자가 기억하는 섬 지형은 예전 버전으로 보인다(미확인).
- 바이옴 6개를 `multi_noise`로 배치하고 하늘·안개 색, 음악을 바이옴마다 다르게 줬다. 가시, 모노리스, 나무는 Java feature.
- 저중력은 매 틱 Y 속도 +0.07, 낙하 거리 -5, 피해 0.5배. 우리는 1.21.1의 `generic.gravity`·`safe_fall_distance` 속성으로 대신할 계획.
- 울트라홀은 포켓몬 스폰 시스템으로 뜨는 엔티티(오버월드 공중 Y100~140, 바다·강 제외). 진입 좌표를 플레이어 NBT에 저장해 그 자리로 돌려보낸다.
- 울비는 바이옴 조건만 붙인 일반 스폰(레벨 60, rarity 0.5). 텅비드는 울트라 심해, 매시붕은 울트라 정글.
