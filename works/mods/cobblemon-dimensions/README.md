# Cobblemon Dimensions

울트라스페이스, 고대, 미래 차원을 추가하는 jbro 서버용 Fabric 모드입니다.

- Mod ID: `cobblemon_dimensions`
- 실행 환경: 서버와 클라이언트 모두 필요(포탈 블록, 하늘·안개 연출)
- 필요 모드: Fabric API, Fabric Language Kotlin, Cobblemon 1.8.1, Terralith
- 차원 ID: `cobblemon_dimensions:ultra_space`, `cobblemon_dimensions:ancient`, `cobblemon_dimensions:future`

## 울트라스페이스

Terralith 오버월드 지형을 섬 모양으로 잘라 공중에 띄운 차원입니다. 섬 아래는 허공입니다.

- 바이옴 6개: 울트라딥시, 울트라데저트, 울트라정글, 울트라포레스트, 울트라크레이터, 울트라플랜트. Terralith가 사막 협곡을 두는 자리는 울트라데저트, 화산을 두는 자리는 울트라크레이터가 되는 식으로, Terralith 지형 모양을 그대로 살립니다.
- 중력이 평소의 1/5입니다. 플레이어에게만 적용됩니다.
- 섬 밖으로 떨어지면 들어오기 전 위치로 돌아갑니다.
- 울트라비스트가 바이옴별로 극희귀 스폰됩니다(레벨 60, 베베놈 40). 아고용은 진화로만 얻습니다.

| 바이옴 | 울트라비스트 |
|---|---|
| 울트라딥시 | 텅비드 |
| 울트라정글 | 매시붕, 베베놈 |
| 울트라데저트 | 페로코체, 악식킹, 차곡차곡 |
| 울트라플랜트 | 전수목 |
| 울트라크레이터 | 철화구야 |
| 울트라포레스트 | 종이신도, 두파팡 |

바이옴 배치와 바이옴 파일은 `works/tools/cobblemon-dimensions/gen_ultra_space.py`가 Terralith jar에서 만듭니다. 매핑이나 색을 바꾸면 스크립트를 고치고 다시 돌립니다.

## 고대·미래

지금은 Terralith 오버월드를 그대로 쓰는 임시 차원입니다. 하늘·안개 색만 다릅니다(고대는 호박색, 미래는 보라 하늘에 시안 안개).

엔드 포탈처럼 틀 블록 12개를 3x3 구멍 둘레에 깔고(모서리 제외) 부싯돌과 부시로 틀을 누르면 포탈이 열립니다.

| 포탈 | 틀 블록 | 포탈 면 색 |
|---|---|---|
| 고대 | 깎은 심층암 | 주황·적색 |
| 미래 | 깎은 구리(산화·밀랍 상태 상관없음) | 보라 |

- 틀 블록은 `data/cobblemon_dimensions/tags/block/ancient_portal_frame.json`, `future_portal_frame.json` 블록 태그로 정합니다. 블록을 바꿀 때는 이 파일만 고치면 됩니다.
- 차원 안에서 같은 포탈을 지어 들어가면 들어오기 전 위치로 돌아갑니다.
- 틀이 하나라도 부서지면 포탈이 꺼집니다.

## 세 차원 공통

- 침대와 리스폰 앵커를 쓸 수 없습니다.
- 들어오기 전 위치는 서버를 껐다 켜도 남습니다. 광장과 마이룸을 다녀와도 바뀌지 않습니다.
- 인벤세이브는 서버 게임룰(`keepInventory`)을 따릅니다. 개발 서버는 켜져 있습니다.

## 관리자 명령어

권한 레벨 2가 필요합니다. 울트라홀이 생기기 전까지 확인용으로 씁니다. 광장·마이룸처럼 `enter`/`exit`을 씁니다.

- `/cdim enter <ultra_space|ancient|future>`: 0, 0 근처의 땅으로 들어갑니다.
- `/cdim exit`: 들어오기 전 위치로 돌아갑니다.
