# Cobblemon Dimensions

울트라스페이스, 고대, 미래 차원을 추가하는 jbro 서버용 Fabric 모드입니다.

- Mod ID: `cobblemon_dimensions`
- 실행 환경: 서버와 클라이언트 모두 필요(포탈 블록, 울트라홀, 하늘·안개 연출)
- 필요 모드: Fabric API, Fabric Language Kotlin, Cobblemon 1.8.1, Terralith
- 선택 모드: More Cobblemon Contents: League Challenge(울트라홀·포탈 진입 자격)
- 설정 파일: `config/cobblemon-dimensions.json`(울트라홀 빈도·크기·유지 시간)
- 차원 ID: `cobblemon_dimensions:ultra_space`, `cobblemon_dimensions:ancient`, `cobblemon_dimensions:future`
- 스폰표: [docs/SPAWNS.md](docs/SPAWNS.md)

세 차원 모두 Terralith 오버월드 지형 함수를 씁니다. 다만 지형 시드를 차원마다 따로 만들어서(월드 시드와 차원 이름을 섞음), 같은 좌표라도 오버월드와 지형이 다릅니다. 이 시드는 서버를 연 뒤에 바꾸면 이미 만들어진 청크와 새 청크 사이에 경계가 생깁니다. Terralith 바이옴 배치표를 통째로 가져와서 바이옴 이름만 이 모드의 바이옴으로 바꾸기 때문에, 사막 협곡 자리는 협곡 모양 그대로 울트라데저트나 고대 사막이 됩니다. 바이옴, 배치표, 스폰 데이터, 스폰표는 `works/tools/cobblemon-dimensions/gen_dimensions.py`가 만듭니다. 바꿀 때는 스크립트를 고치고 다시 돌립니다.

## 울트라스페이스

Terralith 지형을 섬 모양으로 잘라 공중에 띄운 차원입니다. 섬 밑면은 종유석처럼 늘어지고, Y 140 근처에 작은 하늘 섬이 드문드문 떠 있습니다. 섬 아래는 허공입니다.

- 바이옴 6개: 울트라딥시, 울트라데저트, 울트라정글, 울트라포레스트, 울트라크레이터, 울트라플랜트
- 중력이 평소의 1/5입니다. 플레이어에게만 적용됩니다.
- 섬 밖으로 떨어지면 들어오기 전 위치로 돌아갑니다.
- 울트라비스트(픽셀몬 스폰표 기준)와 일반 포켓몬이 바이옴별로 나옵니다.
- 섬 모양 조절은 `worldgen/density_function/ultra_space/`의 값으로 합니다.

### 울트라홀

울트라스페이스로 들어가는 유일한 길입니다. 하얗게 빛나는 중심, 무지갯빛 테두리, 돌아가는 소용돌이로 그린 균열이 하늘에 잠깐 열립니다.

- **작은 홀**: 오버월드에 있는 플레이어 근처, 머리 위 15~30칸 높이에 가끔 열립니다(기본 평균 30분마다, 1분 유지).
- **거대한 홀**: 가끔 아무 플레이어 근처 48~128칸 거리에 크게 열리고, 좌표 없이 서버 전체에 공지됩니다(기본 평균 2시간마다, 5분 유지).
- **귀환 홀**: 울트라스페이스 안의 플레이어 근처에 열립니다(기본 평균 8분마다, 1분 유지). 들어가면 들어오기 전 위치로 돌아갑니다.
- 홀에 닿으면 울트라스페이스의 비슷한 위치, 발을 디딜 수 있는 땅으로 떨어집니다.
- **진입 자격**: 일반 리그에서 사천왕과 챔피언을 이긴 플레이어만 들어갈 수 있습니다. 자격이 없으면 채팅에 빨간 글씨로 "아직 들어갈 자격이 없는 것 같다."가 뜹니다. League Challenge가 설치되지 않은 서버에서는 누구나 들어갑니다.

## 고대

원시 밀림, 고대 사막, 태고의 화산, 고대 초원, 고대 바다로 이루어진 오버월드형 차원입니다.

- 하늘과 안개는 호박색이고 구름이 낮게 깔립니다. 태양이 두 배 크고 붉습니다.
- 습한 아지랑이가 오버월드보다 가까이 깔립니다. 원시 밀림과 화산에서 더 짙습니다.
- 화산엔 화산재, 밀림엔 포자, 사막엔 흰 먼지가 날립니다.

## 미래

강철 산맥, 수정 지대, 네온 숲, 미래 평원, 미래 바다로 이루어진 오버월드형 차원입니다.

- 보라 하늘에 시안 안개가 깔리고 구름이 없습니다. 북쪽 하늘에 오로라가 일렁이고(밤에 더 밝음), 낮에도 별이 보입니다.
- 가까이는 맑고 멀리만 흐립니다. 네온 숲에서는 조금 더 짙습니다. 밤에도 지평선과 안개가 시안빛으로 은은하게 남습니다.
- 네온 숲엔 포자, 수정 지대엔 빛 조각, 강철 산맥과 평원엔 전기 불꽃이 날립니다.

## 패러독스

- 전설이 아닌 패러독스 14종이 고대(7종)·미래(7종) 차원의 정해진 바이옴에 아주 드물게 나옵니다. 일반 포켓몬처럼 몇 마리든 잡을 수 있고, 나타나면 jbro-policy가 서버에 알립니다. 위치는 스폰표에 있습니다.
- 코라이돈·미라이돈(엔트리: 패러독스 아무거나)과 전설 패러독스 6종(엔트리: 코라이돈·미라이돈)은 jbro-policy의 전설 스폰으로 이 차원들에만 나옵니다.

## 고대·미래 포탈

엔드 포탈처럼 틀 블록 12개를 3x3 구멍 둘레에 깔고(모서리 제외) 부싯돌과 부시로 틀을 누르면 포탈이 열립니다.

| 포탈 | 틀 블록 | 포탈 면 색 |
|---|---|---|
| 고대 | 깎은 심층암 | 주황·적색 |
| 미래 | 깎은 구리(산화·밀랍 상태 상관없음) | 보라 |

- 틀 블록은 `data/cobblemon_dimensions/tags/block/ancient_portal_frame.json`, `future_portal_frame.json` 블록 태그로 정합니다. 블록을 바꿀 때는 이 파일만 고치면 됩니다.
- **진입 자격**: 울트라홀과 같습니다. 일반 리그에서 사천왕과 챔피언을 이긴 플레이어만 들어갈 수 있고, 자격이 없으면 채팅에 빨간 글씨로 "아직 들어갈 자격이 없는 것 같다."가 뜹니다. 포탈을 여는 건 누구나 할 수 있습니다.
- 차원 안에서 같은 포탈을 지어 들어가면 들어오기 전 위치로 돌아갑니다. 돌아갈 때는 자격을 따지지 않습니다.
- 틀이 하나라도 부서지면 포탈이 꺼집니다.

## 세 차원 공통

- 침대와 리스폰 앵커를 쓸 수 없습니다. 쓰려고 하면 채팅에 빨간 글씨로 안내가 뜹니다.
- 들어오기 전 위치는 서버를 껐다 켜도 남습니다. 광장과 마이룸을 다녀와도 바뀌지 않습니다.
- 인벤세이브는 서버 게임룰(`keepInventory`)을 따릅니다. 개발 서버는 켜져 있습니다.
- 바닐라 몹은 나오지 않고, 포켓몬만 나옵니다. 야생 포켓몬은 Cobblemon 기본 스폰 데이터를 바이옴마다 맡은 태그대로 가져오며(등급·가중치·조건 그대로, 레벨은 리그 챌린지가 플레이어 레벨 캡에 맞춰 정함), 바이옴별 목록은 스폰표에 있습니다.
- 하늘·안개 연출 값은 `client/CobblemonDimensionsClient.kt`, 오로라는 `client/SkyExtras.kt`, 바이옴 파티클은 생성 스크립트의 `PARTICLES`에서 정합니다. 셰이더팩(Iris 등)을 쓰면 일부 연출이 셰이더팩 쪽으로 대체될 수 있습니다(확인 안 함).

## 관리자 명령어

권한 레벨 2가 필요합니다. 확인용이며, 광장·마이룸처럼 `enter`/`exit`을 씁니다. 진입 자격은 따지지 않습니다.

- `/cdim enter <ultra_space|ancient|future>`: 0, 0 근처의 땅으로 들어갑니다.
- `/cdim exit`: 들어오기 전 위치로 돌아갑니다.
- `/cdim wormhole [small|great|return]`: 근처 하늘에 울트라홀을 바로 엽니다. 홀에 닿을 때는 진입 자격을 따집니다.

## 개발용 캡처

`works`에서 `gradlew :cobblemon-dimensions:runCapture`를 실행하면, 새 월드를 만들어 포탈·울트라홀·각 차원을 찍은 뒤 스스로 꺼집니다. 사진은 `run/screenshots/cdim-*.png`에 남습니다.
