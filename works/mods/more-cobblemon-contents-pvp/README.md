# More Cobblemon Contents: PvP

<img src="src/main/resources/assets/more_cobblemon_contents_pvp/icon.png" alt="More Cobblemon Contents: PvP icon" width="128">

MCC에 플레이어 대전방과 배틀 라운지를 추가하는 애드온입니다.

## 주요 기능

- 배틀 허브를 통한 플레이어 대전방 관리
- 플레이어 간 포켓몬 대전과 배틀 라운지
- 대전 결과와 기록, 공통 전투 시스템 연동
- 승부가 난 대전은 전체 채팅에 "A이(가) B에게 싱글배틀 1:1에서 승리했습니다!"처럼 알림. 이름은 표시 이름이라 Styled Nicknames 닉네임이 그대로 나옴(무승부·취소는 알리지 않음)
- 랭크배틀: 싱글·더블 형식별 매칭 큐와 레이팅(쇼다운 래더 Elo, 1000에서 시작·1000 아래로 안 내려감). 결과도 전체 채팅에 "[랭크] …"로 알리고, 두 사람에게는 레이팅 변화를 따로 보냄

## 설치

**클라이언트와 서버 양쪽에 설치합니다.** 싱글플레이에서도 같은 클라이언트 모드를 사용합니다.

| 항목 | 요구 사항 |
|---|---|
| Minecraft / Java | Java Edition 1.21.1 / Java 21 이상 |
| 로더 | Fabric Loader 0.19.5 이상 |
| 공통 필수 모드 | Fabric API, Fabric Language Kotlin 1.14.1+kotlin.2.4.20 이상, Cobblemon 1.8.1 이상 / 1.9.0 미만 |
| 기반 모드 | More Cobblemon Contents Core 0.1.0 이상 / 1.0.0 미만 |
| 선택 모드 | Mod Menu — 모드 목록 및 지원하는 설정 안내에 사용 |

1. 서버와 접속할 클라이언트의 `mods` 폴더에 모드 JAR과 필수 모드를 넣습니다. 필요한 지원 라이브러리는 각 의존 모드의 설치 안내를 따릅니다.
2. 본체와 사용하려는 애드온을 같은 구성으로 설치합니다. 애드온은 본체 없이 사용할 수 없습니다.
3. 플레이어는 `/mcc` 또는 콘텐츠의 홀로그램 터미널로 배틀 허브를 엽니다. 서버에서 해당 탭을 허용해야 접근할 수 있습니다.

## 설정과 콘텐츠 편집

PvP 탭 위쪽에 "랭크배틀"과 "사용자 설정" 탭이 있습니다. 두 탭 모두 왼쪽은 내 정보(모델, 이름, 랭크 탭에서 고른 형식의 레이팅·순위·승패·승률·최고 레이팅), 오른쪽은 탭 내용입니다. 방에 들어가면 분할 없이 방 화면만 나옵니다.

랭크배틀은 형식(싱글·더블)을 고르고 "매칭 시작"을 누르면 큐에 들어갑니다. 허브를 닫아도 큐는 서버에서 계속 돌고, 화면 오른쪽 아래에 대기 시간과 [GUI 열기]·[취소]가 나옵니다(취소 버튼은 채팅창을 열었을 때 누를 수 있음). 처음에는 레이팅 차이 100 안의 상대만 찾고, 10초마다 50씩 넓히다 60초가 지나면 누구와도 붙습니다. 방금 붙은 상대와는 30초 동안 다시 붙지 않습니다. 랭크 규칙은 새 방의 기본값과 같습니다(최대 6마리 중 싱글 3·더블 4 선출, 메가진화, 같은 포켓몬·도구 금지). 상대를 찾으면 바로 선출 화면이 열리고, 끝나면 허브가 랭크 탭으로 다시 열립니다. 선출 화면을 닫아도 오른쪽 아래 막대(남은 선출 시간, [GUI 열기])로 다시 열 수 있습니다. 선출 중 취소·접속 종료는 나간 사람의 패배로 레이팅이 바뀌고 채팅에도 알립니다(서버 문제로 배틀이 시작되지 못한 경우는 제외). 배틀 중 접속 종료도 기권 패입니다. 큐에서 빠지면(파티 규칙 위반, 다른 방·대전 입장, PvP 꺼짐) 이유가 채팅으로도 나옵니다. 레이팅은 월드 `data/mcc_pvp_ranked.sqlite`에 저장됩니다.

사용자 설정 탭은 기존 방 목록입니다. 플레이어는 허브의 PvP 화면에서 방과 대전 옵션을 관리합니다. 방 설정은 공개 범위, 배틀 형식, 허용 기믹, 중복 금지(포켓몬·도구)입니다. 중복 금지는 기본으로 둘 다 켜져 있고, 켜 둔 항목은 등록 파티 안에서 겹칠 수 없습니다(폼이 달라도 같은 종은 같은 포켓몬). 방장은 "플레이어 초대"에서 접속 중이고 다른 방·대전에 있지 않은 플레이어를 여러 명 연달아 초대할 수 있으며, 초대받은 사람은 방의 규칙이 적힌 팝업과 채팅 줄로 답합니다. 현재 별도 Mod Menu 설정 화면은 없습니다.

대전방과 기록 처리는 서버가 관리합니다. 이 모드에 없는 별도의 클라이언트 설정 파일을 만들 필요는 없습니다. 서버 관리자는 MCC 본체의 허브 탭 설정에서 PvP 접근을 구성할 수 있습니다. 본체의 `content_switches.json`에서 `"more_cobblemon_contents:pvp": false`로 두고 `/mcc reload`하면 재시작 없이 PvP를 쉬게 할 수 있습니다. 이미 시작한 방과 대전은 끝까지 진행되고, 새로 시작하는 것만 막힙니다. 쉬는 동안에는 방을 새로 만들거나 들어갈 수 없습니다.

## 문제 해결

- 모드가 로드되지 않으면 클라이언트·서버의 모드 구성과 필수 의존성을 확인하세요.
- 허브에 콘텐츠가 보이지 않으면 해당 애드온 설치 여부와 본체의 `hub_tabs.json` 설정을 확인하세요.
- 데이터팩을 수정한 뒤 문제가 생기면 서버 로그에서 잘못된 콘텐츠 정의를 확인하세요. 모드 JAR을 직접 수정하는 대신 서버 데이터팩을 사용합니다.
