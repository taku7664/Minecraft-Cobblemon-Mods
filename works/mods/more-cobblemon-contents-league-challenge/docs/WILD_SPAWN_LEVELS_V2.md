## 1. 외부 동작 계약

- 지역 기준값 MUST 기본 10~83 범위에서 월드 시드·차원·위치로 결정된다. 플레이어의 캡이나 첫 방문 당시 캡은 이 값에 영향을 주지 않는다.
- 시작 구역 MUST 기준값 10이다. 시작 구역은 첫 사용 시 저장한 월드 스폰 위치가 들어 있는 구역이다. 저장 후 월드 스폰 위치를 옮겨도 원점은 바뀌지 않는다.
- 구역 MUST 기본 4×4청크(64×64블록)이며, 같은 구역의 지역 기준값은 같다.
- 인접 지역의 기준값 SHOULD 점진적으로 바뀐다. 기본 설정에서 상하좌우로 붙은 구역의 차이는 최대 5이다.
- 고레벨 지역 MUST 확률에 의존하지 않고 존재한다. 기본 설정에서는 원점에 상대적인 32×32구역(2,048×2,048블록) 권역마다 기준값 83인 구역이 최소 하나 있다.
- 스폰 시 적용하는 지역 최종 값 MUST `min(지역 기준값, 스폰을 일으킨 플레이어의 League 캡)`이다.
- 개체 레벨 MUST 지역 최종 값에서 9~3 낮은 정수 사이를 양끝 포함 균등 추첨한다. 포켓몬의 최저 레벨은 1이며, League의 기본 캡은 16 이상이다.
- 실제 개체 레벨 MUST 구역 기준값 범위 10~83으로 제한하지 않는다. 최고 지역에서 캡이 충분하면 74~80, 시작 지역에서는 1~7이다.
- 이미 존재하는 포켓몬 MAY 기존 레벨을 유지한다. 이 계약은 새로 발생한 플레이어 원인의 주인 없는 Cobblemon 스폰에 적용한다.
- CLC의 자체 스폰 레벨 조정 MUST 꺼져 있고, 포획 캡 제한 MUST 켜져 있어야 한다. 기존 적용 제외·충돌 처리와 종의 진화 단계·기술 재계산은 유지한다.

## 2. 구현과 설정

`wild_level` 기본값:

```json
{
  "below_cap": 6,
  "spread": 3,
  "region_chunks": 4,
  "region_min": 10,
  "region_max": 83,
  "transition_regions": 16
}
```

`below_cap`과 `spread`는 플레이어 캡이 아니라 **지역 최종 값**에 대한 중심 감소량과 양쪽 폭이다. 지역 최종 값이 24이면 `(24 - 6) ± 3`, 즉 15~21이다. 최소 감소량은 3 이상으로 제한한다.

`transition_regions`는 앵커 사이 구역 수다. 앵커 값은 시드·차원·좌표로 계산하고, 각 2×2 앵커 권역에서 하나를 최고 값으로 보장한다. 최고 앵커 위치도 권역별로 결정적으로 고른다. 시작 원점 앵커는 최저 값이며 그 권역의 최고 앵커는 다른 위치를 사용한다. 구역 값은 네 앵커를 선형 보간해 반올림한다.

시작 원점 청크 좌표는 오버월드 `data/league_wild_spawn_origin.dat`에 저장한다. 새 포켓몬이 스폰될 때 처음 생성하며, 모든 차원은 이 원점 좌표와 각 차원의 시드를 사용한다. 구역별 방문 기록이나 개별 레벨 목록은 저장하지 않는다.

이전 `floor_level`은 더 이상 지원하지 않는다. 해당 필드가 있는 데이터팩은 명시적으로 거부하고 위 필드로 옮기도록 안내한다. 설정 변경 후 `/reload`하면 새 규칙이 새 스폰에 적용된다. 지역 설정·시드·차원·원점이 같다면 재시작하거나 플레이어 캡이 바뀌어도 실제 지역 기준값은 같다.

## 3. 채택하지 않은 방식

- 플레이어 캡에 맞춰 구역의 고정값 자체를 정하지 않는다. 첫 방문 때 낮은 캡이면 챔피언 이후에도 해당 지역이 영구적으로 낮아지는 문제가 있다.
- 넓은 범위를 추첨한 뒤 최종 개체 레벨을 캡으로 clamp하지 않는다. 높은 지역에서 대부분의 개체가 같은 상한 레벨로 몰린다.
- 모든 구역에서 10부터 높은 레벨까지 추첨하고 확률만 기울이지 않는다. 한 장소에서 10·50·90처럼 큰 편차가 생긴다.
- 최고 지역을 완전 무작위에 맡기지 않는다. 운에 따라 넓은 범위에 고레벨 지역이 없을 수 있다.

## 4. 이전 규칙 종료

기존 문서의 넓은 10~캡−3 추첨과 128×128 격자 규칙은 2026-10-09에 종료한다. 기존 본문은 결정 이력으로 보존하며, 현재 구현이나 별도 호환 분기로 계속 사용하지 않는다.
