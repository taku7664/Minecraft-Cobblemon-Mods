# More Cobblemon Contents: League Challenge

Progress through gyms, badges, ranks, the Elite Four and Champion battles. This MCC addon uses a dedicated terminal and GUI, with league rules defined by server data packs and level-cap integration.

## Installation

Install on **both the server and every connecting client**. Supports Minecraft Java 1.21.1 and Java 21, with Fabric Loader 0.19.5+, Fabric API, Fabric Language Kotlin 1.14.1+kotlin.2.4.20+ and Cobblemon 1.8.1 or newer, below 1.9.0.

Requires More Cobblemon Contents Core 0.1.x and its dependencies. This addon does not run on its own. League Challenge also requires PokeBadges and Cobbled Level Control 1.2.x.

Open the hub with `/mcc` or a content terminal. The server controls which tabs are available.

## Configuration

Mod Menu provides a configuration guide. League rules, teams and rewards are defined in server data packs; level caps integrate with Cobbled Level Control. The guide does not edit server rules from the client.
