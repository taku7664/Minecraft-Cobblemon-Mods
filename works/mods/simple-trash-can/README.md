# Simple Trash Can

서바이벌 인벤토리 오른쪽 바깥, 메인 인벤토리 마지막 줄 높이에 휴지통 슬롯 하나를 붙입니다. 슬롯 위에 "휴지통" 글자가 있고, 비어 있으면 휴지통 아이콘이 보입니다.

## 동작

- 아이템을 올려도 바로 지워지지 않고 슬롯에 남습니다. 다시 꺼낼 수 있습니다.
- 다른 아이템을 올리면 그때 원래 아이템이 지워지고 새 아이템이 남습니다. 같은 아이템은 그대로 쌓입니다.
- 넣을 때는 직접 끌어다 놓거나 숫자키·보조손 키로 넣습니다. Shift+클릭으로는 들어가지 않고, 휴지통에서 Shift+클릭하면 인벤토리로 돌아옵니다. 더블클릭으로 같은 아이템을 모을 때도 휴지통은 건드리지 않습니다.
- 인벤토리를 닫아도 남아 있습니다. 저장하지 않으므로 접속을 끊거나 튕기면 사라집니다.
- 죽으면 사라집니다(바닥에 떨어지지 않음). 게임룰 `keepInventory`가 켜져 있으면 그대로 남습니다.
- 크리에이티브 인벤토리 탭에는 보이지 않습니다. 크리에이티브에는 자체 삭제 슬롯이 있습니다.

패널 테두리와 슬롯은 현재 리소스팩의 인벤토리 텍스처에서 잘라 그립니다. EMI가 있으면 아이템 목록이 패널을 가리지 않습니다.

## 설치

슬롯이 서버 메뉴에도 있어야 해서 **클라이언트와 서버 양쪽에** 설치해야 합니다. Fabric API가 필요합니다. 설정 화면은 없습니다.

## 빌드

`works/`에서 AGENTS.md의 F 드라이브 경로를 지정한 뒤 실행합니다.

```powershell
.\gradlew.bat :simple-trash-can:build
```
