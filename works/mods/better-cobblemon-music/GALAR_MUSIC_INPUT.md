# 가라르 리그 BGM과 연결 키

빡대리가 제공한 소드·실드 MP3 7곡을 OGG Vorbis로 변환해 공식 음악팩에 등록했습니다. 같은 곡을 쓰는 일반·하드·트레이너별 키는 하나의 플레이리스트와 물리 OGG 파일을 공유하며 파일 사본을 만들지 않습니다.
한 전투 안에서는 같은 곡을 유지합니다. 다이맥스·마지막 포켓몬에 따른 중간 전환은 없습니다.

| 음원 | 재생 대상 | 물리 파일명 |
|---|---|---|
| 소드·실드 체육관 관장전 | 두송을 제외한 가라르 관장 9명 | `galar_gym_leader.ogg` |
| 두송전 | 두송 일반·하드 관장전 | `galar_piers.ogg` |
| 마리전 | 챔피언컵 마리전 | `galar_marnie.ogg` |
| 호브전 | 챔피언컵 호브전 | `galar_hop.ogg` |
| 비트전 | 챔피언컵 비트전 | `galar_bede.ogg` |
| 챔피언컵 토너먼트 | 컵의 야청·채두/어니언·금랑전 | `galar_champion_cup.ogg` |
| 챔피언 단델전 | 컵 마지막 단델전 | `galar_leon.ogg` |

총 **7종**입니다. 일반·하드에서 같은 파일을 공유하며 설정 키는 분리합니다.
사용자가 지정한 원본의 편곡·구성과 길이를 보존합니다.

## 연결 키

모든 키의 접두사는 `more_cobblemon_contents:league_challenge/galar/`입니다.

| 음원 | 일반 키 | 하드 키 |
|---|---|---|
| 관장 공통 | `gym` | `hard_gym` |
| 두송 | `gym/piers` | `hard_gym/piers` |
| 마리 | `tournament/marnie` | `hard_tournament/marnie` |
| 호브 | `tournament/hop` | `hard_tournament/hop` |
| 비트 | `tournament/bede` | `hard_tournament/bede` |
| 토너먼트 공통 | `tournament` | `hard_tournament` |
| 단델 | `champion/leon` | `hard_champion/leon` |

개별 관장 키도 설정 화면에서 선택할 수 있습니다. 우선순위는 개별 트레이너 → 같은 지방·난이도·역할 → 리그 콘텐츠 공통입니다.
가라르 음원이 없어도 신오 전용 관장·사천왕 키로 넘어가지는 않습니다. 실제 재생은 기존 공통/일반 전투 설정에 따릅니다.
관장 10명·컵 상대 7명·단델의 일반/하드 전투와 역할 공통 키까지 총 42개 콘텐츠 키를 등록합니다. 컵의 야청·채두·어니언·금랑은 관장전 전용곡 대신 파이널 토너먼트 곡을 공유합니다.

## 변환·음량

- MP3 첫 오디오 스트림만 사용하고 표지·영상·기존 메타데이터를 제거합니다.
- OGG Vorbis 품질 4, 스테레오, 44,100 Hz로 저장하며 자르기·반복 편집·다이내믹 압축은 하지 않습니다.
- 기존 신오 관장곡의 실측 -15.84 LUFS를 기준으로 곡마다 일정한 게인을 적용합니다. 인코딩 후 결과는 -16.01~-15.97 LUFS이며, 기존 전투 재생 보정 0.713은 유지합니다.
- 곡별 원본명, SHA-256, 크기, 게인, 길이, 변환 전후 LUFS·피크는 `resource-pack/galar-import-2026-10-16.json`에 기록합니다.
- 전체 디코딩·길이 보존·키→플레이리스트→이벤트→단일 파일 연결은 자동 검증 대상입니다. 실게임 청취 여부는 작업 기록에서 별도로 확인합니다.
