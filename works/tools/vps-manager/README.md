# 빡케몬 VPS 관리

바탕화면 **빡케몬 VPS 관리**를 열면 VPS 상태와 Git 변경 파일을 확인하고 버튼으로 서버를 관리합니다.
PowerShell 7과 기존 SSH 키를 사용하며 서버 저장소에는 관리 프로그램을 설치하지 않습니다.

## 사용

1. **상태 / 변경 검사**로 변경 파일을 불러옵니다.
2. JSON·properties·모드·광장 등 올릴 파일만 체크하고 커밋 메시지를 적습니다.
3. **선택 파일 커밋·푸시**를 누르고 파일 목록을 확인합니다. 실행 중인 서버는 월드 저장·정상 종료 후 백업하고, 선택 파일만 커밋·푸시한 뒤 다시 시작합니다. 이미 꺼져 있었으면 꺼진 상태를 유지합니다.

**광장만 선택**은 광장 차원 파일을 빠르게 체크하는 보조 버튼입니다. 다른 파일도 자유롭게 선택할 수 있습니다.
**기존 커밋 푸시**는 푸시가 실패해 로컬에 남은 커밋을 다시 전송합니다. 새 파일을 커밋하지 않습니다.
비밀 설정·키·플레이어 기록·일반 월드는 목록에서 제외합니다. 알려진 자격 증명 파일과 일반적인 비밀값 필드도 검사합니다.

**업데이트 검사**는 GitHub를 조회하고 적용·보존할 경로를 표시합니다. **기능 업데이트 적용**은
모드·위키·기능 데이터팩 등의 새 파일을 설치합니다. 기존 설정·실행 옵션·시작 규칙과 월드·광장·플레이어 데이터를 보존합니다.
생성된 `world/datapacks/cobblemon-startup-hooks.zip`도 보존합니다. 직접 수정한 기능 파일과 업데이트가 겹치거나
Git 브랜치가 분기된 경우 적용을 중단합니다. 기존 로컬 커밋은 푸시한 뒤 다시 검사하세요.

기존 상태를 보존하면서 커밋 정보를 갱신하므로 보존한 파일은 Git에서 계속 수정 상태로 표시될 수 있습니다.
업데이트 실패 시 교체한 기능 파일과 커밋 정보만 복구하며, 월드 백업을 자동으로 덮어쓰지 않습니다.
정상 종료 실패 시 강제로 끄거나 파일을 교체하지 않습니다.

**서버 시작 / 서버 종료 / 서버 콘솔**도 같은 창에서 사용할 수 있습니다. 기동 완료 로그와 게임 포트를 확인합니다.
기존 `tmux ppakemon`을 사용하며 GUI나 SSH 연결을 닫아도 서버 콘솔은 유지됩니다.
변경 작업은 SSH와 분리된 원격 작업자로 실행하고 결과를 재조회하므로 일시적인 연결 끊김에도 작업이 유지됩니다.
다른 관리 작업은 원격 잠금으로 동시에 실행하지 않습니다.

## 설치와 설정

커밋된 main에서 아래 설치기를 실행합니다.

```powershell
pwsh -NoProfile -File .\works\tools\vps-manager\install-vps-manager.ps1
```

설치본은 `%LOCALAPPDATA%/PPakemonVpsManager`에 두며 개발·배포 서버 폴더에 넣지 않습니다.
설치본 SHA-256을 원본과 비교합니다. **연결 설정**은 로컬 `settings.json`을 엽니다.
SSH 호스트·키 파일 경로·서버 루트·tmux 세션·Git 작성자 정보를 바꾼 뒤 프로그램을 다시 열면 적용됩니다.
키 파일의 내용과 계정 토큰을 설정에 복사하지 않습니다. 설치기 재실행은 기존 설정을 보존합니다.

백업은 VPS의 `~/.local/share/ppakemon-backups/manager/<작업번호>/`에 있습니다.
`world-snapshot.tar`는 정상 종료 시점의 월드 전체이고 `settings-snapshot.tar`는 설정·실행 옵션입니다.
교체한 기능 파일은 `files/`에 보관합니다. 백업을 자동 삭제하지 않으므로 필요에 따라 용량을 관리하세요.
원격 작업 결과는 `~/.local/share/ppakemon-manager/jobs/`에 보관합니다.

## 검증

Python 표준 `unittest`로 실제 임시 Git 저장소에서 파일 선택·보존·복구·실패 처리를 검증합니다.
테스트 임시 폴더는 F 드라이브를 지정하고 `PYTHONDONTWRITEBYTECODE=1`로 소스 옆 캐시 생성을 끕니다.
`vps-manager.ps1 -Probe`는 GUI와 같은 SSH 경로로 VPS 상태만 확인합니다.
`-RenderUiPath <png>`는 샘플 행을 사용한 화면 검증용이며 서버에 접속하지 않습니다.
